# 7、生产综合配置模板

两份**完整、可独立粘贴**的 `nginx.conf`：**HTTPS 版**（公网生产）和 **HTTP 版**（内网/开发）。部署路径与 [Deploy/4、nginx.md](../../05-运维和部署/Deploy/4、nginx.md) 一致。

```bash
vi /data/nginx/current/conf/nginx.conf
nginx -t -p /data/nginx/current/ -c conf/nginx.conf
nginx -s reload -p /data/nginx/current/ -c conf/nginx.conf
```

---

## 1、选哪一份？

| 版本 | 适用 | 监听 | 特点 |
|------|------|------|------|
| **HTTPS 版** | 公网、正式生产、需 TLS | 80 跳转 + **443** | 证书、HTTP/2、HSTS 可选 |
| **HTTP 版** | 内网、K8s 集群内、开发测试 | **80** | 无证书、省内存、配置更简单 |

> 两套 **http 全局块 + upstream + location** 逻辑一致，仅 server 层不同。**二选一**整文件粘贴，不要混在同一份里开两个 server 块版本。

---

## 2、按服务器内存怎么配？

Nginx **不像 JVM 按内存百分比设堆**；主要吃内存的是：**Worker 数 × 连接数 × buffer + 缓存区**（HTTPS 另加 `ssl_session_cache`）。

### 2.1 专用 Nginx 网关节点

| 物理内存 | worker_connections | upstream keepalive | proxy_cache | ssl_session_cache（仅 HTTPS） | 适用 |
|----------|--------------------|--------------------|-------------|-------------------------------|------|
| **1GB** | **2048** | 16 | 不开 | `10m` / HTTP 无 | 开发 |
| **2GB** | **4096** | 32 | 可选 `50m` | `20m` / HTTP 无 | 中小生产 |
| **4GB** | **8192** | 64 | `100m` / 500m 盘 | `50m` / HTTP 无 | **常见生产** |
| **8GB+** | **10240～16384** | 128 | `200m` / 1g 盘 | `50m` / HTTP 无 | 高并发 |

**理论最大连接** ≈ `worker_processes × worker_connections`（还受 `ulimit`、后端限制）。

**HTTP 版比 HTTPS 版省**：无 `ssl_session_cache`（4GB 档约省 50MB），连接握手更轻。

### 2.2 与 Java 同机混部

| 物理内存 | Nginx 建议 |
|----------|------------|
| **4GB** | `worker_connections 2048`，不开 proxy_cache |
| **8GB** | `worker_connections 4096`，小 cache |
| **16GB+** | 按上表 4GB/8GB 档 |

### 2.3 系统参数

```bash
# /etc/security/limits.conf
nginx soft nofile 65535
nginx hard nofile 65535

# /etc/sysctl.conf
net.core.somaxconn = 65535
net.ipv4.ip_local_port_range = 1024 65535
net.ipv4.tcp_tw_reuse = 1
```

## 3、完整 nginx.conf — HTTPS 版（公网生产）

基准：**4GB 内存 / 4 核 / 前后端分离 + TLS**。粘贴后改 `server_name`、证书路径、upstream、root。

```nginx
# =============================================================================
# Nginx 生产配置 — HTTPS 版
# 路径：/data/nginx/current/conf/nginx.conf
# 场景：公网 / 正式生产；80 强制跳 443
# 必改：server_name、ssl 证书、upstream IP、root 静态目录
# 内存档位：[1G]2048 [2G]4096 [4G]8192 [8G]16384 → worker_connections
# =============================================================================

# ========== 全局块 ==========
user  nginx;
worker_processes  auto;           # [1G] 可写死 2
worker_rlimit_nofile 65535;
pid run/nginx.pid;

# ========== events 块 ==========
events {
    use epoll;
    worker_connections  8192;   # 见文首内存表
    multi_accept on;
}

# ========== http 块 ==========
http {
    include       mime.types;
    default_type  application/octet-stream;

    client_body_temp_path tmp/client_body;
    proxy_temp_path       tmp/proxy;
    fastcgi_temp_path     tmp/fastcgi;
    scgi_temp_path        tmp/scgi;
    uwsgi_temp_path       tmp/uwsgi;

    log_format  main  '$remote_addr - $remote_user [$time_local] "$request" '
                      '$status $body_bytes_sent "$http_referer" '
                      '"$http_user_agent" "$http_x_forwarded_for" '
                      'upstream:$upstream_addr '
                      'rt:$request_time urt:$upstream_response_time';
    access_log  logs/access.log  main;
    error_log   logs/error.log   warn;

    sendfile        on;
    tcp_nopush      on;
    tcp_nodelay     on;
    keepalive_timeout   65;
    keepalive_requests  10000;
    types_hash_max_size 2048;

    gzip  on;
    gzip_disable  "msie6";
    gzip_vary     on;
    gzip_proxied  any;
    gzip_comp_level  6;
    gzip_min_length  1k;
    gzip_buffers  16 8k;
    gzip_types text/plain text/css application/json application/javascript
               text/xml application/xml application/xml+rss text/javascript;

    client_max_body_size        50m;    # [1G]20m [8G]100m
    client_body_buffer_size     512k;
    client_header_buffer_size   64k;
    large_client_header_buffers 4 64k;

    send_timeout          60;
    client_body_timeout   60;
    client_header_timeout 60;

    server_tokens off;

    limit_req_zone $binary_remote_addr zone=req_per_ip:10m rate=20r/s;
    limit_conn_zone $binary_remote_addr zone=conn_per_ip:10m;

    # [1G] 建议注释整段 proxy_cache
    proxy_cache_path /data/nginx/current/cache levels=1:2
                     keys_zone=proxy_cache:100m
                     max_size=500m inactive=60m use_temp_path=off;

    upstream backend {
        server 192.168.1.101:8080 max_fails=3 fail_timeout=30s;
        server 192.168.1.102:8080 max_fails=3 fail_timeout=30s;
        server 192.168.1.103:8080 max_fails=3 fail_timeout=30s;
        keepalive 64;                 # [1G]16 [2G]32 [8G]128
    }

    # ========== HTTP → HTTPS 跳转 ==========
    server {
        listen 80;
        listen [::]:80;
        server_name example.com www.example.com;
        return 301 https://$host$request_uri;
    }

    # ========== HTTPS 主站 ==========
    server {
        listen 443 ssl http2;
        listen [::]:443 ssl http2;
        server_name example.com www.example.com;

        ssl_certificate     /data/nginx/current/conf/ssl/example.com/fullchain.pem;
        ssl_certificate_key /data/nginx/current/conf/ssl/example.com/privkey.pem;
        ssl_session_timeout 1d;
        ssl_session_cache   shared:SSL:50m;   # [1G]10m [2G]20m
        ssl_protocols       TLSv1.2 TLSv1.3;
        ssl_ciphers ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-RSA-AES256-GCM-SHA384;
        ssl_prefer_server_ciphers on;

        add_header X-Frame-Options "SAMEORIGIN" always;
        add_header X-Content-Type-Options "nosniff" always;
        # add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;

        location / {
            root   /data/www/dist;
            index  index.html;
            try_files $uri $uri/ /index.html;
        }

        location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff2)$ {
            root  /data/www/dist;
            expires 30d;
            add_header Cache-Control "public, immutable";
        }

        location ~* \.(html|htm)$ {
            root  /data/www/dist;
            expires -1;
            add_header Cache-Control "no-cache, no-store, must-revalidate";
        }

        location /api/ {
            limit_req zone=req_per_ip burst=40 nodelay;
            limit_conn conn_per_ip 50;

            proxy_pass http://backend;
            proxy_http_version 1.1;
            proxy_set_header Host              $host;
            proxy_set_header X-Real-IP         $remote_addr;
            proxy_set_header X-Forwarded-For   $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto https;
            proxy_set_header Connection        "";

            proxy_connect_timeout 60s;
            proxy_send_timeout    60s;
            proxy_read_timeout    60s;

            proxy_buffering on;
            proxy_buffers              16 64k;   # [1G]8 32k [8G]32 64k
            proxy_busy_buffers_size    128k;
            proxy_temp_file_write_size 128k;

            # proxy_cache proxy_cache;
            # proxy_cache_valid 200 10m;
            # proxy_cache_methods GET HEAD;
            # add_header X-Cache-Status $upstream_cache_status;
        }

        location /ws/ {
            proxy_pass http://backend;
            proxy_http_version 1.1;
            proxy_set_header Upgrade    $http_upgrade;
            proxy_set_header Connection "upgrade";
            proxy_set_header Host       $host;
            proxy_read_timeout 3600s;
        }

        location /nginx_status {
            stub_status on;
            allow 127.0.0.1;
            allow 192.168.1.0/24;
            deny all;
        }

        location ~ /\.(?!well-known) {
            deny all;
            access_log off;
            log_not_found off;
        }
    }
}
```

## 4、完整 nginx.conf — HTTP 版（内网 / 开发）

基准：**4GB 内存 / 4 核 / 内网 HTTP**。无 SSL、无 80→443 跳转；**一个 server 监听 80** 搞定静态 + API。

```nginx
# =============================================================================
# Nginx 生产配置 — HTTP 版
# 路径：/data/nginx/current/conf/nginx.conf
# 场景：内网、开发测试、K8s Ingress 后端、纯 HTTP 微服务入口
# 必改：server_name、upstream IP、root 静态目录
# 勿用于公网裸奔；公网请用上方 HTTPS 版
# =============================================================================

# ========== 全局块 ==========
user  nginx;
worker_processes  auto;
worker_rlimit_nofile 65535;
pid run/nginx.pid;

# ========== events 块 ==========
events {
    use epoll;
    worker_connections  8192;   # [1G]2048 [2G]4096 [8G]16384
    multi_accept on;
}

# ========== http 块 ==========
http {
    include       mime.types;
    default_type  application/octet-stream;

    client_body_temp_path tmp/client_body;
    proxy_temp_path       tmp/proxy;
    fastcgi_temp_path     tmp/fastcgi;
    scgi_temp_path        tmp/scgi;
    uwsgi_temp_path       tmp/uwsgi;

    log_format  main  '$remote_addr - $remote_user [$time_local] "$request" '

                      '"$http_user_agent" "$http_x_forwarded_for" '
                      'upstream:$upstream_addr '
                      'rt:$request_time urt:$upstream_response_time';
    access_log  logs/access.log  main;
    error_log   logs/error.log   warn;

    sendfile        on;
    tcp_nopush      on;
    tcp_nodelay     on;
    keepalive_timeout   65;

    gzip  on;

    client_max_body_size        50m;
    client_body_buffer_size     512k;
    client_header_buffer_size   64k;
    large_client_header_buffers 4 64k;

    send_timeout          60;
    client_body_timeout   60;
    client_header_timeout 60;

    server_tokens off;

    limit_req_zone $binary_remote_addr zone=req_per_ip:10m rate=20r/s;

    server {
        listen 80;
        listen [::]:80;

        server_name example.com 192.168.1.100;

        add_header X-Frame-Options "SAMEORIGIN" always;
        add_header X-Content-Type-Options "nosniff" always;

        location / {
            root   /data/www/dist;
            index  index.html;
            try_files $uri $uri/ /index.html;

        location ~* \.(html|htm)$ {
            root  /data/www/dist;
            expires -1;
            add_header Cache-Control "no-cache, no-store, must-revalidate";
        }

        location /api/ {
            limit_req zone=req_per_ip burst=40 nodelay;
            limit_conn conn_per_ip 50;

            proxy_pass http://backend;
            proxy_http_version 1.1;
            proxy_set_header Host              $host;
            proxy_set_header X-Real-IP         $remote_addr;
            proxy_set_header X-Forwarded-For   $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;   # HTTP 版用 $scheme
            proxy_set_header Connection        "";

            proxy_connect_timeout 60s;
            proxy_send_timeout    60s;
            proxy_read_timeout    60s;

            proxy_buffering on;
            proxy_buffers              16 64k;
            proxy_busy_buffers_size    128k;
            proxy_temp_file_write_size 128k;

            # proxy_cache proxy_cache;
            # proxy_cache_valid 200 10m;
```

## 5、两版差异对照

| 项 | HTTPS 版 | HTTP 版 |
|----|----------|---------|
| 监听 | 80（301 跳转）+ **443 ssl http2** | **仅 80** |
| 证书 | 需要 fullchain + privkey | 不需要 |
| `ssl_session_cache` | 有（占内存） | 无 |
| `X-Forwarded-Proto` | 固定 `https` | `$scheme`（http） |
| 防火墙 | 开 80、443 | 开 80 |
| 适用 | 公网域名 | 内网 IP、开发机 |

---

## 6、粘贴前必改清单

| 类别 | HTTPS 版 | HTTP 版 |
|------|----------|---------|
| 必改 | 域名、**证书路径**、upstream、root | **server_name/IP**、upstream、root |
| 按内存 | worker_connections、keepalive、proxy_cache、ssl_session_cache | worker_connections、keepalive、proxy_cache |
| 部署前 | `nginx -t`；防火墙 80+443 | `nginx -t`；防火墙 80 |

## 7、各内存档位快速改法（两版通用）

```nginx
# 1GB
worker_processes 2;
worker_connections 2048;
# upstream keepalive 16;  proxy_buffers 8 32k;  client_max_body_size 20m;
# HTTPS 另：ssl_session_cache shared:SSL:10m;  注释 proxy_cache_path

# 2GB
worker_connections 4096;
# keepalive 32;  ssl_session_cache shared:SSL:20m;  (HTTPS)

# 8GB
worker_connections 16384;
# keepalive 128;  proxy_buffers 32 64k;  client_max_body_size 100m;
```
