# 3、配置文件详解

Nginx 主配置文件通常为 `nginx.conf`，站点可按模块拆到 `conf.d/*.conf`。

## 1、配置块层次

```text
全局块（main context）
events { ... }
http {
    # http 全局
    upstream { ... }
    server {
        location { ... }
    }
}
```

| 块 | 作用域 | 常见指令 |
|----|--------|----------|
| **全局** | 整个 Nginx | `user`、`worker_processes`、`error_log` |
| **events** | 连接处理模型 | `worker_connections`、`use epoll` |
| **http** | HTTP 相关 | `gzip`、`keepalive_timeout`、`include` |
| **server** | 虚拟主机 | `listen`、`server_name` |
| **location** | URI 匹配 | `root`、`proxy_pass`、`rewrite` |

---

## 2、生产 nginx.conf 示例（带注释）

```nginx
# ========== 全局块 ==========
# 运行 Nginx 的工作进程用户（Worker 以此用户运行）
user  nginx;
# Worker 进程数；auto=按 CPU 核数；生产常用 auto 或 = 核数
worker_processes  auto;
# 单个 Worker 进程最大打开文件数（须 ≤ 系统 ulimit）
worker_rlimit_nofile 65535;
# Master 进程 PID 文件
pid run/nginx.pid;

# ========== events 块 ==========
events {
    # Linux 下高性能 IO 模型
    use epoll;
    # 每个 Worker 最大并发连接数
    # 理论最大连接 ≈ worker_processes × worker_connections
    worker_connections  16384;
    # 一次 accept 多个新连接，提高并发
    multi_accept on;
}

# ========== http 块 ==========
http {
    # MIME 类型映射
    include       mime.types;
    default_type  application/octet-stream;

    # ========== 临时目录 ==========
    client_body_temp_path tmp/client_body;
    proxy_temp_path       tmp/proxy;
    fastcgi_temp_path     tmp/fastcgi;

    # ========== 日志 ==========
    log_format  main  '$remote_addr - $remote_user [$time_local] "$request" '
                      '$status $body_bytes_sent "$http_referer" '
                      '"$http_user_agent" "$http_x_forwarded_for" '
                      'upstream:$upstream_addr rt:$request_time';
    access_log  logs/access.log  main;
    error_log   logs/error.log   warn;

    # ========== 传输优化 ==========
    sendfile        on;      # 零拷贝发送静态文件
    tcp_nopush      on;      # 配合 sendfile，减少报文
    tcp_nodelay     on;      # 禁用 Nagle，降低小数据包延迟
    keepalive_timeout  65;    # 客户端长连接超时（秒）
    keepalive_requests 10000;  # 单连接最多处理请求数

    # ========== Gzip ==========
    gzip  on;
    gzip_vary  on;
    gzip_proxied  any;
    gzip_comp_level  6;
    gzip_min_length  1k;
    gzip_types text/plain text/css application/json application/javascript text/xml;

    # ========== 客户端请求限制 ==========
    client_max_body_size       50m;   # 上传大小上限
    client_body_buffer_size    512k;
    client_header_buffer_size  64k;
    large_client_header_buffers 4 64k;

    # ========== 超时 ==========
    send_timeout         60;
    client_body_timeout  60;
    client_header_timeout 60;

    # 隐藏版本号（安全）
    server_tokens off;

    # 引入站点配置
    include conf.d/*.conf;
}
```

## 3、全局块重要参数

| 参数 | 说明 | 生产建议 |
|------|------|----------|
| `user` | Worker 运行用户 | `nginx` 或专用用户 |
| `worker_processes` | Worker 数量 | `auto` 或 CPU 核数 |
| `worker_rlimit_nofile` | Worker 最大 fd | 65535，配合系统 limits |
| `error_log` | 错误日志路径与级别 | `warn` 或 `error` |

**理论最大连接数**

```text
max_connections ≈ worker_processes × worker_connections
```

例：8 Worker × 16384 = 131072（还受 `ulimit -n`、后端能力限制）

---

## 4、events 块重要参数

| 参数 | 说明 |
|------|------|
| `use epoll` | Linux 推荐；FreeBSD 用 `kqueue` |
| `worker_connections` | 单 Worker 最大连接（含代理连接） |
| `multi_accept` | 一次 accept 多个连接 |

---

## 5、http 全局常用参数

| 参数 | 说明 |
|------|------|
| `sendfile on` | 内核直接传文件到 socket，少一次用户态拷贝 |
| `keepalive_timeout` | HTTP 长连接空闲超时 |
| `client_max_body_size` | 请求体上限；文件上传必调 |
| `server_tokens off` | 响应头不暴露 Nginx 版本 |
| `gzip on` | 压缩文本类响应，省带宽 |

## 6、server 块基础

```nginx
server {
    # 监听端口；default_server 表示该 IP:端口默认站点
    listen       80;
    listen       [::]:80;   # IPv6（可选）
    # 匹配的域名；多个用空格分隔；_ 表示兜底
    server_name  example.com www.example.com;

    # 访问日志可单独指定
    access_log logs/example.access.log main;

    location / {
        root   html;
        index  index.html;
    }
}
```

**server_name 匹配优先级**（从高到低）

1. 精确匹配 `server_name example.com;`
2. 通配符开头 `*.example.com`
3. 通配符结尾 `mail.*`
4. 正则 `~^www\d+\.example\.com$`
5. 默认：第一个 `listen` 带 `default_server` 的 server

## 7、常用内置变量

| 变量 | 含义 |
|------|------|
| `$host` | 请求 Host 头 |
| `$remote_addr` | 客户端 IP |
| `$proxy_add_x_forwarded_for` | 追加 X-Forwarded-For |
| `$scheme` | http 或 https |
| `$request_uri` | 完整 URI（含参数） |
| `$uri` | 不含参数的 URI |
| `$args` | 查询字符串 |
| `$status` | 响应状态码 |
| `$upstream_addr` | 实际转发的后端地址 |
| `$request_time` | 请求总耗时（秒） |

## 8、include 拆分配置

**推荐结构**

```text
/data/nginx/current/conf/
├── nginx.conf          # 全局 + events + http 框架
└── conf.d/
    ├── default.conf    # 默认站点
    ├── api.conf        # API 反向代理
    └── ssl.conf        # HTTPS 站点
```

```nginx
# nginx.conf 的 http 块内
include conf.d/*.conf;
```

改单个站点后 `nginx -t && nginx -s reload` 即可。
