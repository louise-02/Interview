# 2、安装与目录规划

> 完整安装命令（yum / 编译 / Docker / systemd）见 [Deploy/4、nginx.md](../../05-运维和部署/Deploy/4、nginx.md)。

## 1、安装方式对比

| 方式 | 适用 | 优点 | 缺点 |
|------|------|------|------|
| **yum / apt** | 快速验证、小项目 | 一条命令、易维护 | 版本可能偏旧；模块固定 |
| **编译安装** | 生产、需自定义模块 | 版本可控、可加 stub_status/ssl 等 | 步骤多 |
| **Docker** | 开发测试、容器化网关 | 隔离好、配置挂载 | 生产需额外考虑网络与证书 |

---

## 2、yum 安装（快速上手）

```bash
sudo yum install -y epel-release
sudo yum install -y nginx

sudo systemctl start nginx
sudo systemctl enable nginx
nginx -v
```

**默认路径（yum）**

| 类型 | 路径 |
|------|------|
| 主程序 | `/usr/sbin/nginx` |
| 配置 | `/etc/nginx/nginx.conf`、`/etc/nginx/conf.d/` |
| 静态页 | `/usr/share/nginx/html/` |
| 日志 | `/var/log/nginx/access.log`、`error.log` |

---

## 3、编译安装目录规范（生产推荐）

与 Deploy 文档一致：**程序与数据分离**。

```bash
# 程序目录（版本 + current 软链）
/opt/nginx/1.26.2/
/opt/nginx/current  → 1.26.2

# 数据目录（配置、html、日志、pid、临时文件）
/data/nginx/1.26.2/
/data/nginx/current → 1.26.2
  ├── conf/       # nginx.conf、conf.d/
  ├── html/       # 静态资源
  ├── logs/       # access.log、error.log
  ├── run/        # nginx.pid
  └── tmp/        # proxy/client_body 等临时目录
```

**常用编译参数**

```bash
./configure \
  --prefix=/opt/nginx/1.26.2 \
  --with-http_ssl_module \
  --with-http_stub_status_module \
  --with-http_gzip_static_module
```

| 模块 | 作用 |
|------|------|
| `http_ssl_module` | HTTPS |
| `http_stub_status_module` | 连接数监控 `/nginx_status` |
| `http_gzip_static_module` | 预压缩 `.gz` 静态文件 |

## 4、Docker 安装（简要）

```bash
mkdir -p /data/docker/nginx/{conf,conf.d,html,logs}

docker compose -f nginx.yml up -d
docker exec nginx nginx -t
docker exec nginx nginx -s reload
```

配置挂载：`conf/nginx.conf` + `conf.d/*.conf` → 容器内 `/etc/nginx/`。

---

## 5、启停与配置重载

```bash
# 测试配置语法（改配置后必做）
nginx -t
# 编译安装需指定前缀
nginx -t -p /data/nginx/current/ -c conf/nginx.conf

# 启动
nginx -p /data/nginx/current/ -c conf/nginx.conf

# 平滑重载（不中断服务，推荐）
nginx -s reload

# 优雅停止（处理完当前请求再退出）
nginx -s quit

# 快速停止
nginx -s stop
```

| 信号/命令 | 作用 |
|-----------|------|
| `reload` | 重新加载配置，Worker 优雅替换 |
| `quit` | 优雅退出 |
| `stop` | 立即停止 |
| `reopen` | 重新打开日志文件（配合 logrotate） |

**reload 原理**：Master 收到 reload → 校验新配置 → 启动新 Worker → 旧 Worker 处理完现有连接后退出。

## 6、systemd 管理（生产）

```ini
[Unit]
Description=Custom Nginx
After=network.target

[Service]
Type=forking
ExecStart=/opt/nginx/current/sbin/nginx -p /data/nginx/current/ -c /data/nginx/current/conf/nginx.conf
ExecReload=/opt/nginx/current/sbin/nginx -s reload -p /data/nginx/current/ -c /data/nginx/current/conf/nginx.conf
ExecStop=/opt/nginx/current/sbin/nginx -s quit -p /data/nginx/current/ -c /data/nginx/current/conf/nginx.conf
PIDFile=/data/nginx/current/run/nginx.pid
LimitNOFILE=65536

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable nginx
sudo systemctl start nginx
sudo systemctl reload nginx
```

## 7、环境变量

```bash
vi /etc/profile.d/nginx.sh
export PATH=/opt/nginx/current/sbin:$PATH
source /etc/profile.d/nginx.sh
```

---

## 8、多版本切换

```bash
ln -sfn /opt/nginx/1.27.0 /opt/nginx/current
ln -sfn /data/nginx/1.27.0 /data/nginx/current
nginx -t && sudo systemctl restart nginx
```
