# 3、常用函数

## 3.1 数学 / 聚合

| 函数 | 说明 |
| ---- | ---- |
| `ABS` `CEILING` `FLOOR` `ROUND(x,y)` `TRUNCATE(x,y)` | 绝对值、取整、四舍五入、截断 |
| `MOD(x,y)` `EXP` `LN` `LOG(x,y)` `SQRT` `RAND()` | 模、幂、对数、根号、随机 |
| `GREATEST` `LEAST` | 多值最大/最小 |
| `COUNT(col)` | 非 NULL 计数 |
| `GROUP_CONCAT(expr)` | 组内拼接，如 `GROUP_CONCAT(name ORDER BY id SEPARATOR ',')` |

```sql

```

## 3.2 字符串

| 函数 | 说明 / 示例 |
| ---- | ----------- |
| `SUBSTRING_INDEX(str, delim, n)` | 按分隔符截取，`SUBSTRING_INDEX('a:b', ':', 1)` → `a` |
| `FIND_IN_SET(str, list)` | 逗号分隔 list 中 str 的位置 |
| `LOCATE(sub, str)` / `POSITION(sub IN str)` | 子串位置 |
| `SUBSTRING(str, pos, len)` `LEFT` `RIGHT` | 截取 |
| `LOWER` / `UPPER` `TRIM` `LENGTH` | 大小写、去空格、长度 |
| `CONCAT_WS(sep, s1, s2...)` | 带分隔符拼接 |
| `FIELD(str, v1, v2...)` | 自定义排序：`ORDER BY FIELD(status, 'urgent', 'normal')` |
| `REPEAT` `REVERSE` `STRCMP(s1,s2)` | 重复、反转、比较（0 相等） |

```sql

SELECT FIND_IN_SET('b', 'a,b,c');                     -- 2
SELECT * FROM user ORDER BY FIELD(username, '4', '1') DESC;
```

## 3.3 日期时间

**查当天（可走索引，优于对列包 `DATE_FORMAT`）**

```sql
WHERE dt >= CURDATE() AND dt < CURDATE() + INTERVAL 1 DAY;
```

**常用**

| 函数 | 说明 |
| ---- | ---- |
| `NOW()` `CURDATE()` `CURTIME()` | 当前日期时间 |
| `DATE_FORMAT(d, fmt)` `STR_TO_DATE(s, fmt)` | 格式化 / 解析 |
| `DATE_ADD(d, INTERVAL n DAY)` `DATE_SUB` | 加减 |
| `DATEDIFF(d1,d2)` `TIMEDIFF(t1,t2)` | 日期/时间差 |
| `TIMESTAMPDIFF(unit, d1, d2)` `TIMESTAMPADD` | 带单位的差/加 |
| `UNIX_TIMESTAMP()` / `FROM_UNIXTIME(ts)` | 时间戳互转 |
| `LAST_DAY(d)` `CONVERT_TZ(ts, from, to)` | 月末、时区 |

```sql
-- 近一个月
SELECT * FROM t
 WHERE DATE_FORMAT(publish_time, '%Y-%m-%d')
       BETWEEN DATE_FORMAT(DATE_SUB(NOW(), INTERVAL 1 MONTH), '%Y-%m-%d')
           AND DATE_FORMAT(NOW(), '%Y-%m-%d');

SELECT DATE_ADD(NOW(), INTERVAL 1 DAY);
SELECT DATEDIFF('2008-08-08', '2008-08-01');   -- 7
SELECT UNIX_TIMESTAMP('2008-08-08 12:30:00');
```

`DATE_FORMAT` 常用：`%Y` 年 · `%m` 月 · `%d` 日 · `%H` 时 · `%i` 分 · `%s` 秒 · `%W` 星期

# 4、查询技巧

## 4.1 UNION

- `UNION`：去重 + 排序，慢
- `UNION ALL`：直接合并，快
- 子查询各自 `ORDER BY` 须包一层并起别名：

```sql
SELECT * FROM (SELECT * FROM t1 ORDER BY col) a
UNION
SELECT * FROM (SELECT * FROM t2 ORDER BY col) b;
```

## 4.2 行转列 / 列转行

**行转列（IF + GROUP BY，最常用）**

```sql
SELECT userid,
       SUM(IF(subject = '语文', score, 0)) AS 语文,
       SUM(IF(subject = '数学', score, 0)) AS 数学,
       SUM(IF(subject = '英语', score, 0)) AS 英语
  FROM tb_score
 GROUP BY userid;

-- 汇总行
SELECT IFNULL(userid, 'TOTAL') AS userid, SUM(score) AS total
  FROM tb_score GROUP BY userid WITH ROLLUP;

-- 合并展示
SELECT userid, GROUP_CONCAT(subject, ':', score) AS 成绩
  FROM tb_score GROUP BY userid;
```

**列转行**

```sql
SELECT userid, '语文' AS course, cn_score AS score FROM tb_wide
UNION ALL SELECT userid, '数学', math_score FROM tb_wide
UNION ALL SELECT userid, '英语', en_score FROM tb_wide;
```

**逗号分隔字符串拆行**（小数据可用 `mysql.help_topic`）

```sql
SELECT SUBSTRING_INDEX(SUBSTRING_INDEX('张三,李四,王五', ',', help_topic_id + 1), ',', -1) AS name
  FROM mysql.help_topic
 WHERE help_topic_id < LENGTH('张三,李四,王五') - LENGTH(REPLACE('张三,李四,王五', ',', '')) + 1;
```

## 4.3 删除重复

```sql
-- 保留 id 较大者
DELETE t1 FROM t t1
 INNER JOIN t t2 ON t1.email = t2.email AND t1.id < t2.id;

-- 临时表重建
CREATE TABLE tmp AS SELECT * FROM t GROUP BY col1, col2;
DROP TABLE t;
ALTER TABLE tmp RENAME TO t;
```

## 4.4 IN 超过 1000 条

1. 写入临时表再 `JOIN`
2. MyBatis 每 1000 条拆 `OR ... IN (...)`（见 §5.5）

## 4.5 树形递归

**MySQL 8+**

```sql
WITH RECURSIVE tree AS (
    SELECT id, pid FROM node WHERE id = :root
    UNION ALL
    SELECT n.id, n.pid FROM node n INNER JOIN tree t ON n.pid = t.id
)
SELECT * FROM tree;
```

# 6、SQL 优化

## 6.1 慢查询

**临时开启**

```sql
-- 查看慢查询相关配置
SHOW VARIABLES LIKE '%slow_query_log%';
SHOW VARIABLES LIKE '%long_query_time%';

-- 开启慢查询（重启失效）
SET GLOBAL slow_query_log = ON;
SET GLOBAL long_query_time = 3;   -- 超过 3 秒记录
```

**永久配置（my.cnf）**

```ini
slow_query_log = ON
slow_query_log_file = /var/log/mysql/slow.log
long_query_time = 3
```

## 6.2 常用原则

| 场景 | 建议 |
| ---- | ---- |
| 小表驱动大表 | 结果集小的做驱动表；先子查询过滤再 JOIN |
| IN vs EXISTS | 子查询结果少、外表大有索引 → IN；反之 EXISTS |
| 最左前缀 | 索引 `(a,b,c)` 条件尽量带 `a` |
| 隐式转换 | 字符串列勿与数字比：`mobile = 13800138000` 致索引失效 |
| 深分页 | 延迟关联或 `id BETWEEN`，避免大 `OFFSET` |
| 否定条件 | 索引列少用 `NOT` `!=` `NOT IN` `NOT LIKE` |
| 多列模糊 | `LOCATE('kw', CONCAT(col1, col2))` |

```sql
-- 小表驱动大表
SELECT a.* FROM big_table a
 INNER JOIN (
       SELECT MAX(id) mid FROM big_table
        WHERE DATEDIFF(NOW(), ts) <= 7 GROUP BY title LIMIT 30
 ) b ON b.mid = a.id;

-- 深分页：延迟关联
SELECT t.* FROM t
 INNER JOIN (SELECT id FROM t WHERE a = 1 ORDER BY c DESC LIMIT 10000, 10) x ON t.id = x.id;

-- EXISTS
SELECT * FROM t1 WHERE EXISTS (SELECT 1 FROM t2 WHERE t2.id = t1.id);
```

## 6.3 EXPLAIN 速查

```sql
EXPLAIN SELECT ...;
EXPLAIN FORMAT=JSON SELECT ...;   -- 8.0
```

| 列 | 关注点 |
| -- | ------ |
| `type` | `system` > `const` > `eq_ref` > `ref` > `range` > `index` > `ALL` |
| `key` | 实际使用的索引 |
| `rows` | 预估扫描行数 |
| `Extra` | `Using filesort` / `Using temporary` / `Using index` |

# 12、窗口函数

语法骨架：`FUNC() OVER (PARTITION BY ... ORDER BY ... [frame])`

| 函数 | 作用 |
| ---- | ---- |
| `ROW_NUMBER()` | 连续序号 1,2,3… |
| `RANK()` | 排名，并列后跳号 |
| `DENSE_RANK()` | 排名，并列不跳号 |
| `PERCENT_RANK()` | 百分位，约 `(rank-1)/(rows-1)` |
| `LAG(col,n)` / `LEAD(col,n)` | 上/下 n 行 |
| `FIRST_VALUE` / `LAST_VALUE` / `NTH_VALUE` | 窗口首/末/第 n 值 |
| `CUME_DIST()` | 累积分布 |
| `NTILE(n)` | 分 n 桶 |

```sql
-- 排名
SELECT val,
       ROW_NUMBER() OVER (ORDER BY val) AS rn,
       DENSE_RANK()    OVER (ORDER BY val) AS dr
  FROM t;

-- 每组下一单日期
SELECT customer_id, order_date,
       LEAD(order_date, 1) OVER (
         PARTITION BY customer_id ORDER BY order_date
       ) AS next_order_date
  FROM orders;

-- LAST_VALUE 默认窗口到当前行；取分区末值需显式 frame
SELECT employee_name, hours,
       LAST_VALUE(employee_name) OVER (
         ORDER BY hours
         ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
       ) AS top_overtime
  FROM overtime;
```

# 14、存储过程 / 函数 / 游标

## 14.1 自定义函数

```sql
DELIMITER $$
CREATE FUNCTION hello(name VARCHAR(50))
RETURNS VARCHAR(50)
DETERMINISTIC
BEGIN
  RETURN CONCAT('hello', name);
END$$
DELIMITER ;

SELECT hello('world');
```

报错 `none of DETERMINISTIC, NO SQL`：`SET GLOBAL log_bin_trust_function_creators = ON`，或加 `DETERMINISTIC` / `NO SQL`。

## 14.2 存储过程

```sql
DELIMITER $$
CREATE PROCEDURE p_min_id(OUT mid BIGINT)
BEGIN
  SELECT MIN(id) INTO mid FROM user;
END$$
DELIMITER ;

CALL p_min_id(@m);
SELECT @m;
```

参数：`IN`（默认）· `OUT` · `INOUT`。`DELIMITER` 用于体内含 `;` 时不被客户端提前截断。

## 14.3 错误处理

```sql
DECLARE CONTINUE HANDLER FOR SQLEXCEPTION SET @err = 1;
DECLARE EXIT HANDLER FOR SQLSTATE '23000' SET @dup = 1;
DECLARE no_table CONDITION FOR 1146;
DECLARE CONTINUE HANDLER FOR no_table SET @info = 'NO_SUCH_TABLE';
```

处理方式：`CONTINUE` 继续 · `EXIT` 退出 · `UNDO`（MySQL 不支持）

## 14.4 流程控制

```sql
IF cond THEN ... ELSEIF ... ELSE ... END IF;

CASE expr WHEN v1 THEN ... WHEN v2 THEN ... ELSE ... END CASE;

-- LOOP / WHILE / REPEAT
add_loop: LOOP
  SET id = id + 1;
  IF id >= 10 THEN LEAVE add_loop; END IF;
END LOOP add_loop;

WHILE i < 10 DO SET i = i + 1; END WHILE;

REPEAT SET i = i + 1; UNTIL i >= 10 END REPEAT;

LEAVE label;      -- break
ITERATE label;    -- continue
```

## 14.5 游标示例

累加薪资最高若干人，直到总和达到阈值，返回人数：

```sql
DELIMITER //
CREATE PROCEDURE get_count_by_limit_total_salary(
    IN limit_total DOUBLE, OUT total_count INT)
BEGIN
    DECLARE sum_salary DOUBLE DEFAULT 0;
    DECLARE cursor_salary DOUBLE DEFAULT 0;
    DECLARE emp_count INT DEFAULT 0;
    DECLARE emp_cursor CURSOR FOR
        SELECT salary FROM employees ORDER BY salary DESC;
    DECLARE CONTINUE HANDLER FOR NOT FOUND SET cursor_salary = NULL;

    OPEN emp_cursor;
    read_loop: LOOP
        FETCH emp_cursor INTO cursor_salary;
        IF cursor_salary IS NULL OR sum_salary >= limit_total THEN
            LEAVE read_loop;
        END IF;
        SET sum_salary = sum_salary + cursor_salary;
        SET emp_count = emp_count + 1;
    END LOOP;
    CLOSE emp_cursor;
    SET total_count = emp_count;
END //
DELIMITER ;
```

## 14.6 递归存储过程（5.7 树形）

边表 `product_id` / `secondary_product_id`，给定根 `tid` 向上向下展开：

```sql
DELIMITER //
CREATE PROCEDURE secondary_product_proc(IN tid VARCHAR(100))
BEGIN
    SET @result := tid;
    SET @temp := tid;
    -- 向下
    WHILE @temp IS NOT NULL DO
        SELECT GROUP_CONCAT(secondary_product_id) INTO @temp
          FROM t_secondary_product WHERE FIND_IN_SET(product_id, @temp);
        SET @result := CONCAT_WS(',', @result, @temp);
    END WHILE;
    SET @temp := tid;
    -- 向上
    WHILE @temp IS NOT NULL DO
        SELECT GROUP_CONCAT(product_id) INTO @temp
          FROM t_secondary_product WHERE FIND_IN_SET(secondary_product_id, @temp);
        SET @result := CONCAT_WS(',', @result, @temp);
    END WHILE;
    SELECT @result;
END //
DELIMITER ;
```

MySQL 8+ 优先用 `WITH RECURSIVE`（§4.5）。

# 15、表大小

字段说明：`table_schema` 库名 · `table_name` 表名 · `table_rows` 记录数（估算） · `data_length` 数据大小 · `index_length` 索引大小

```sql
-- 查看所有数据库容量
SELECT table_schema AS db,
       SUM(table_rows) AS rows,
       ROUND(SUM(data_length)/1024/1024, 2) AS data_mb,
       ROUND(SUM(index_length)/1024/1024, 2) AS idx_mb
  FROM information_schema.tables
 GROUP BY table_schema
 ORDER BY data_mb DESC;

-- 查看指定库各表容量
SELECT table_name, table_rows,
       ROUND(data_length/1024/1024, 2) AS data_mb,
       ROUND(index_length/1024/1024, 2) AS idx_mb
  FROM information_schema.tables
 WHERE table_schema = 'your_db'
 ORDER BY data_length DESC;
```

# 17、虚拟列

```sql
-- 从 CRT_TIME 提取日期部分，便于查询和建索引
ALTER TABLE your_table
  ADD crt_date DATE AS (DATE(crt_time)) STORED;

CREATE INDEX idx_crt_date ON your_table (crt_date);
```

`VIRTUAL`（默认，不占存储）与 `STORED`（物化，可建索引）按场景选择。
