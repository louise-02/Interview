# 4、分页查询

**注意**：`ORDER BY` 字段最好唯一，否则分页可能乱序。

**ROWNUM 经典写法**

```sql
SELECT * FROM (
    SELECT TMP.*, ROWNUM ROW_ID FROM (
        SELECT sid, sname, sage FROM student
         WHERE ...
         ORDER BY sid DESC
    ) TMP WHERE ROWNUM <= :maxRow
) WHERE ROW_ID > :minRow;
```

**12c+ OFFSET FETCH**

```sql
SELECT * FROM user_data
 ORDER BY user_id
 OFFSET 0 ROWS FETCH NEXT 20 ROWS ONLY;
```

## 5.3 日期时间

| 函数 | 说明 |
| ---- | ---- |
| `SYSDATE` | 当前系统日期，不含时间 |
| `CURRENT_DATE` | 当前日期（会话时区），不含时间 |
| `CURRENT_TIMESTAMP` / `SYSTIMESTAMP` | 当前日期时间，含毫秒 |
| `LOCALTIMESTAMP` | 当前本地日期时间 |
| `DBTIMEZONE` | 数据库当前时区 |
| `TO_DATE(str, fmt)` | 字符串 → 日期 |
| `TO_CHAR(d\|n[, fmt])` | 日期/数字 → 字符串 |
| `TO_NUMBER(str[, fmt])` | 字符串 → 数字 |
| `ADD_MONTHS(d, n)` | 日期加 n 月 |
| `LAST_DAY(d)` | 当月最后一天 |
| `EXTRACT(fmt FROM d)` | 提取年/月/日/时/分/秒 |
| `MONTHS_BETWEEN(d1, d2)` | 相差月数 |
| `TRUNC(d)` | 截到当天 0 点，查「当天」常用 |

```sql
SELECT TO_CHAR(SYSDATE, 'yyyy-MM') FROM dual;

-- 日期加减（天数/小时/分钟/秒）
SELECT SYSDATE + 1 FROM dual;              -- 加一天
SELECT SYSDATE + (1/24) FROM dual;         -- 加一小时
SELECT SYSDATE + INTERVAL '1' MONTH FROM dual;

-- 两日期相差（结果为天数；乘 24/1440/86400 得小时/分/秒）
SELECT TO_NUMBER(d1 - d2) FROM dual;
SELECT MONTHS_BETWEEN(d1, d2) FROM dual;

-- 查当天数据（截断时间部分）
SELECT * FROM your_table
 WHERE date_col >= TRUNC(SYSDATE)
   AND date_col < TRUNC(SYSDATE) + 1;
```

**TO_CHAR 常用格式**：`YYYY` `MM` `DD` `HH` `HH24` `MI` `SS` `FF` `FF3` `Q` `DY` `MONTH`

# 6、SQL 技巧

## 6.1 行转列 / 列转行

**PIVOT 行转列**

```sql
SELECT * FROM (
    SELECT id, name, score, subject FROM t_test
)
PIVOT (SUM(score) FOR subject IN (
    'CHINESE' AS 语文, 'MATH' AS 数学, 'ENGLISH' AS 英语
))
ORDER BY id;
```

**UNPIVOT 列转行**

```sql
SELECT id, name, score, subject FROM (
    SELECT id, name, chinese, math, english FROM t_test
)
UNPIVOT (score FOR subject IN (chinese, math, english))
ORDER BY id;
```

## 6.7 KEEP 聚合（每组取首/末）

相较于 `OVER()`：`聚合 + KEEP + OVER` 在子查询中既能排序又避免「返回多行」。

```sql
-- 各部门 hiredate 最早的一人
SELECT d.deptno,
       (SELECT MAX(e.ename) KEEP (DENSE_RANK FIRST ORDER BY e.hiredate)
          FROM emp e
         WHERE e.deptno = d.deptno)
  FROM dept d;
```

语法：`MAX|MIN(col) KEEP (DENSE_RANK FIRST|LAST ORDER BY col2) OVER (PARTITION BY col3)`

# 7、序列

```sql
CREATE SEQUENCE seq_name
    START WITH 1
    INCREMENT BY 1
    MAXVALUE 999999
    NOCYCLE
    CACHE 20;

-- 查询当前值 / 下一个值
SELECT seq_name.CURRVAL, seq_name.NEXTVAL FROM dual;

-- 插入时使用
INSERT INTO t1 VALUES (seq_name.NEXTVAL, ...);

-- 修改序列
ALTER SEQUENCE seq_name INCREMENT BY 10 MAXVALUE 10000 CYCLE;

-- 删除序列
DROP SEQUENCE seq_name;
```

| 参数 | 说明 |
| ---- | ---- |
| `CACHE` | 预生成序列号放内存，性能更好 |
| `NOCACHE` | 不预生成 |
| `CYCLE` / `NOCYCLE` | 到最大/最小值后是否循环 |

# 8、触发器

```sql
CREATE OR REPLACE TRIGGER trg_name
AFTER INSERT OR DELETE OR UPDATE OF col1 ON table_name
FOR EACH ROW
WHEN (条件可选)
BEGIN
    IF INSERTING THEN ...
    ELSIF DELETING THEN ...
    ELSIF UPDATING THEN ...
    END IF;
END;
/
```

**`:OLD` / `:NEW`**：更新/删除前旧值；插入/更新后新值。

## 9.5 导出 / 导入参数

# 11、诊断：正在执行的 SQL

```sql
-- 查询正在执行的 SQL 及用户
SELECT b.sid        AS oracle_id,
       b.username   AS 登录用户名,
       b.serial#,

       c.sql_text, c.sql_fulltext, b.machine, b.event
  FROM gv$process a, gv$session b, gv$sql c

   AND b.sql_hash_value = c.hash_value
   AND b.status = 'ACTIVE';
```

## 12.6 定时杀长时间阻塞 Session（Shell）

等待超过 `WAIT_SECONDS` 的 Session，自动找出**最终阻塞者**（`final_blocking_session`，可处理死锁环）并 `KILL IMMEDIATE`。仅处理指定 schema（`TARGET_USER`）。

**用法**

```bash
chmod +x kill_long_blockers.sh
# 环境变量可覆盖默认值
DB_USER=app DB_PASS=xxx DB_CONN=172.23.0.40:1521/PDBORCL WAIT_SECONDS=30 ./kill_long_blockers.sh

# cron 每 5 分钟
# */5 * * * * /opt/scripts/kill_long_blockers.sh >> /var/log/oracle/kill_blockers.cron.log 2>&1
```

**脚本 `kill_long_blockers.sh`**

```bash
#!/bin/bash
# 杀掉导致其他 Session 等待超过阈值的最终阻塞 Session

set -u

ORACLE_HOME="${ORACLE_HOME:-/u01/app/oracle/product/19.0.0.0}"
export ORACLE_HOME
export PATH="$ORACLE_HOME/bin:$PATH"

DB_USER="${DB_USER:-your_user}"
DB_PASS="${DB_PASS:-your_password}"
DB_CONN="${DB_CONN:-host:1521/service_name}"
TARGET_USER="${TARGET_USER:-$DB_USER}"
WAIT_SECONDS="${WAIT_SECONDS:-30}"
LOG_FILE="${LOG_FILE:-/var/log/oracle/kill_blockers.log}"

KILL_SQL="$(mktemp /tmp/kill_blockers_XXXXXX.sql)"
trap 'rm -f "$KILL_SQL"' EXIT

mkdir -p "$(dirname "$LOG_FILE")"
NOW="$(date '+%Y-%m-%d %H:%M:%S')"

# 1. 记录本次发现的阻塞者（写日志，不参与执行）
{
  echo "======== $NOW scan (wait>${WAIT_SECONDS}s, user=$TARGET_USER) ========"
  sqlplus -S "${DB_USER}/${DB_PASS}@${DB_CONN}" <<EOF
SET HEADING OFF FEEDBACK OFF PAGESIZE 0 VERIFY OFF ECHO OFF LINESIZE 400
SELECT '  blocker sid=' || s.sid || ',serial#=' || s.serial#
     || ' user=' || s.username
     || ' inst=' || s.inst_id
     || ' max_wait_sec=' || ROUND(MAX(v.wait_time_micro) / 1000000)
  FROM v\$session s
  JOIN v\$session v ON v.final_blocking_session = s.sid
 WHERE v.wait_time_micro > ${WAIT_SECONDS} * 1000000
   AND v.final_blocking_session IS NOT NULL
   AND s.username = UPPER('${TARGET_USER}')
   AND s.type != 'BACKGROUND'
 GROUP BY s.sid, s.serial#, s.username, s.inst_id;
EXIT
EOF
} >> "$LOG_FILE" 2>&1

# 2. 生成 KILL 语句（RAC 需带 @inst_id）
sqlplus -S "${DB_USER}/${DB_PASS}@${DB_CONN}" <<EOF > "$KILL_SQL"
SET HEADING OFF FEEDBACK OFF PAGESIZE 0 VERIFY OFF ECHO OFF TRIMSPOOL ON LINESIZE 400
SELECT 'ALTER SYSTEM KILL SESSION ''' || s.sid || ',' || s.serial# || ',@' || s.inst_id || ''' IMMEDIATE;'
  FROM v\$session s
 WHERE s.username = UPPER('${TARGET_USER}')
   AND s.type != 'BACKGROUND'
   AND s.sid IN (
       SELECT DISTINCT v.final_blocking_session
         FROM v\$session v
        WHERE v.wait_time_micro > ${WAIT_SECONDS} * 1000000
          AND v.final_blocking_session IS NOT NULL
   );
EXIT
EOF

# 3. 有 kill 语句才执行
if grep -q 'ALTER SYSTEM KILL SESSION' "$KILL_SQL"; then
  {
    echo "--- $NOW execute ---"
    cat "$KILL_SQL"
    sqlplus -S "${DB_USER}/${DB_PASS}@${DB_CONN}" @"$KILL_SQL"
    echo "--- $NOW done ---"
  } >> "$LOG_FILE" 2>&1
else
  echo "--- $NOW no blocker to kill ---" >> "$LOG_FILE"
fi
```

| 项 | 说明 |
| -- | ---- |
| `final_blocking_session` | 11g+；定位链顶 / 死锁环中的最终阻塞者 |
| `@inst_id` | RAC 必须；单机 inst_id=1 同样可用 |
| `TARGET_USER` | 避免误杀其它 schema 的 Session |

# 13、系统视图速查

## 13.1 前缀说明

| 前缀 | 范围 | 典型用途 |
| ---- | ---- | -------- |
| **USER_** | 当前用户 | 自己的表、列、权限 |
| **ALL_** | 当前用户可见 | 有权限的对象 |
| **DBA_** | DBA | 全库用户、表空间、数据文件 |
| **V$** | 动态性能 | 会话、SQL、参数、实例 |

## 13.2 DBA_ 常见

`dba_users` 用户信息 · `dba_segments` 表段 · `dba_extents` 数据区 · `dba_objects` 对象 · `dba_tablespaces` 表空间 · `dba_data_files` 数据文件 · `dba_free_space` 空闲空间 · `dba_profiles` 资源限制 · `dba_sys_privs` / `dba_tab_privs` / `dba_role_privs` 权限 · `dba_indexes` 索引

## 13.3 USER_ / ALL_ 常见

`user_tables` / `all_tables` 表 · `user_tab_columns` 列 · `user_col_comments` 列注释 · `user_sequences` 序列 · `user_objects` 对象 · `user_constraints` 约束 · `user_indexes` 索引

## 13.4 V$ 常见

`v$database` 库信息 · `v$instance` 实例 · `v$session` 会话 · `v$process` 进程 · `v$sql` / `v$sqlarea` SQL · `v$locked_object` 锁 · `v$parameter` 参数 · `v$datafile` 数据文件

## 13.5 常用查询

```sql
-- 查看字段备注
SELECT * FROM user_col_comments WHERE table_name = 'T';

-- 查看字段信息
SELECT * FROM user_tab_columns WHERE table_name = 'T';

-- 查看建表 DDL
SELECT DBMS_METADATA.GET_DDL('TABLE', 'T', 'SCHEMA') FROM dual;

-- 查看序列
SELECT * FROM user_sequences;

-- 查看某表大小（MB）
SELECT SUM(bytes) / 1024 / 1024
  FROM user_segments
 WHERE segment_name = UPPER('your_table');

-- 查看数据库名 / 实例名 / service
SELECT name, dbid FROM v$database;
SELECT instance_name FROM v$instance;
SELECT value FROM v$parameter WHERE name = 'service_names';
```

# 14、客户端与服务端版本不一致

连接报认证/版本相关错误时：

**修改 Grid Home 下 sqlnet.ora**

```bash
su - grid
cd $ORACLE_HOME/network/admin
vi sqlnet.ora
```

**修改 Oracle Home 下 sqlnet.ora**

```bash
su - oracle
cd $ORACLE_HOME/network/admin
vi sqlnet.ora
```

添加：

```
NAMES.DIRECTORY_PATH= (TNSNAMES, EZCONNECT)
SQLNET.ALLOWED_LOGON_VERSION=8
```

**Grid 下重启监听（RAC）**

```bash
srvctl stop listener
srvctl stop scan_listener
srvctl start listener
srvctl start scan_listener
```

> 单机非 Grid 一般只改 Oracle Home 下 `sqlnet.ora` 即可。
