# 4、版本兼容与生产实践

## 1、版本对应（务必查官方表）

Spring Boot、Spring Cloud、Spring Cloud Alibaba 三者**必须对齐**，随意组合会启动失败或隐性 Bug。

典型（示例，以官方文档为准）：

| Boot | Cloud | Alibaba |
| ---- | ----- | ------- |
| 2.7.x | 2021.0.x | 2021.0.x.x |
| 3.0+ | 2022.0.x+ | 2022.0.x.x+ |

## 2、服务划分原则

- 按**业务能力**拆（用户、订单、商品），非按表拆。
- 单服务职责清晰，避免**分布式单体**（改一行调十个服务）。
- 数据库**归属单一服务**，跨服务不直连别人库。

## 3、配置管理

- 公共配置 Nacos **shared-configs**；服务专属 dataId。
- 敏感配置加密或 K8s Secret。
- 变更走审计，生产禁止控制台随意改（或严格权限）。

## 4、可观测性

- **日志**：JSON + TraceId（MDC）。
- **指标**：Micrometer + Prometheus + Grafana。
- **链路**：SkyWalking / Zipkin。
- **健康**：Actuator health + K8s liveness/readiness。

## 5、容灾与限流

- 核心链路 **Sentinel** 限流熔断。
- 超时传递：Gateway > Feign > 业务。
- 降级页面/默认数据，非核心功能可关。

## 6、发布与回滚

蓝绿、金丝雀（Gateway 权重）、滚动更新；数据库变更**向前兼容**（先加字段后删旧字段）。

## 7、安全

Gateway 统一鉴权 JWT；内网 mTLS 可选；Actuator 不暴露公网；依赖漏洞扫描 OWASP Dependency-Check。

## 8、常见问题

| 现象 | 排查 |
| ---- | ---- |
| 服务注册不上 | Nacos 地址、namespace、网络 |
| Feign 404 | context-path、服务名、接口路径 |
| 配置不刷新 | @RefreshScope、dataId、group |
| 分布式事务慢 | 是否真需要 Seata，能否最终一致 |
