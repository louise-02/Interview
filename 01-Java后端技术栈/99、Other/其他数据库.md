# Postgresql

## 只读用户创建

```sql
# 创建用户
CREATE USER louise WITH ENCRYPTED PASSWORD '1234';
# 设置只读权限
alter user readonly set default_transaction_read_only=on;
# 授予查询权限
GRANT SELECT ON ALL TABLES IN SCHEMA schema_name TO louise;
```

## 日期函数

```sql
# to_char() 日期转字符串
select to_char(now(),'YYYY-MM-dd')

# 获取前一天
select now() + interval '-1 day'
```



# SqlServer

## 日期函数

```sql
# 获取当前系统时间
GETDATE()

# 加日期   
年(yy/yyyy),季度(qq/q),月份(mm/m),日(day/dd/d),
周(wk/ww),小时(hh),分钟(mi,n),秒(ss/s)
DATEADD(datepart,number,date)
DATEADD(day, -1, GETDATE())

# 日期转换
select CONVERT(varchar(12) , getdate(), 111 )   --2004/09/12
select CONVERT(varchar, getdate(), 120 )    --2004-09-12 11:06:08
select CONVERT(varchar(12) , getdate(), 23 )   --2008-04-01
# 前一天
select CONVERT(varchar(12) , getdate() - 1, 23 )   --2008-04-01
```

## ucanaccess

添加依赖

```xml
<dependency>
  <groupId>net.sf.ucanaccess</groupId>
  <artifactId>ucanaccess</artifactId>
  <version>4.0.1</version>
</dependency>
```

查询

```java
public static void main(String[] args) throws ClassNotFoundException, SQLException {
    Class.forName("net.ucanaccess.jdbc.UcanaccessDriver");

    Connection connection = DriverManager.getConnection("jdbc:ucanaccess://D:\\历史数据.mdb", "", "ty123456");
    Statement statement = connection.createStatement();
    ResultSet resultSet = statement.executeQuery("select * from 数据表");
    ArrayList<Integer> list = new ArrayList<>();
    while (resultSet.next()){
        list.add(resultSet.getInt(1));
    }
    System.out.println(list.size());
}
```
