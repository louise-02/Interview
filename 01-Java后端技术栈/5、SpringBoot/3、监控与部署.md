# 3、监控与部署

## 1、Spring Boot Actuator

依赖 `spring-boot-starter-actuator`。

| 端点 | 说明 |
| ---- | ---- |
| `/actuator/health` | 健康检查（K8s probe） |
| `/actuator/info` | 应用信息 |
| `/actuator/metrics` | 指标 |
| `/actuator/env` | 环境（生产需鉴权） |

**安全**：生产只暴露 health；配合 Spring Security 或网关鉴权；`management.endpoints.web.exposure.include=health,info`。

## 2、打包与运行

```bash
mvn package -DskipTests
java -jar app.jar --spring.profiles.active=prod
# 或 Dockerfile 多阶段构建
```

**分层 jar**（Boot 2.3+）：镜像只 COPY 变更层，加速构建。

## 3、Graceful Shutdown

```yaml
server:
  shutdown: graceful
spring:
  lifecycle:
    timeout-per-shutdown-phase: 30s
```

配合 K8s `preStop` + `terminationGracePeriodSeconds`，Drain 进行中的请求。

## 4、DevTools

开发热重启；**生产勿引入**。

## 5、测试

`@SpringBootTest` 集成测试；`@WebMvcTest` 只测 Controller；`MockMvc` 模拟 HTTP。

## 6、常见面试题

**1. Actuator 生产如何加固？**

最小暴露、Security、内网、网关统一入口。

**2. jar 为什么能直接运行？**

内嵌容器 + `Main-Class: JarLauncher` 加载 `BOOT-INF/lib` 与 `BOOT-INF/classes`。

**3. Boot 3 升级注意？**

JDK 17+、`javax.*` → `jakarta.*`、部分配置项更名。
