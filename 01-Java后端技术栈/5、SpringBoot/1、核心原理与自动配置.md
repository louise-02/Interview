# 1、核心原理与自动配置

## 1、@SpringBootApplication 组合

```java
@SpringBootApplication
// = @Configuration + @EnableAutoConfiguration + @ComponentScan
public class Application {
    public static void main(String[] args) {
        SpringApplication.run(Application.class, args);
    }
}
```

## 2、启动流程（简化）

```
SpringApplication.run
  → 创建 ApplicationContext（Servlet 则为 AnnotationConfigServletWebServerApplicationContext）
  → 准备 Environment（加载 application.yml）
  → 刷新 Context：扫描 Bean、执行 AutoConfiguration
  → 内嵌 Tomcat/Jetty/Undertow 启动
  → 发布 ApplicationReadyEvent
```

## 3、自动配置原理

`META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports`（Boot 3）或 `spring.factories`（Boot 2）列出配置类。

典型：`DataSourceAutoConfiguration`、`RedisAutoConfiguration`。

**生效条件**：`@ConditionalOnClass`、`@ConditionalOnMissingBean`、`@ConditionalOnProperty` 等。

**调试**：`--debug` 或 `logging.level.org.springframework.boot.autoconfigure=DEBUG` 看 **Positive/Negative matches**。

## 4、排除自动配置

```java
@SpringBootApplication(exclude = {DataSourceAutoConfiguration.class})
// 或配置 spring.autoconfigure.exclude
```

## 5、内嵌容器

`spring-boot-starter-web` 默认 **Tomcat**；可换 Jetty、Undertow（排除 tomcat 依赖）。

端口：`server.port`；上下文：`server.servlet.context-path`。

## 6、常见面试题

**1. Spring Boot 如何做到开箱即用？**

Starter 聚合依赖 + 自动配置类按条件注册 Bean。

**2. 自动配置和 @Configuration 区别？**

自动配置在 jar 的 META-INF 中，由 `@EnableAutoConfiguration` 导入；普通 @Configuration 在扫描包内。

**3. run 方法做了什么？**

创建上下文、加载配置、刷新容器、启动 Web 服务器、发布生命周期事件。
