# 知识体系总览

集成与类职责见 **[0、生产集成完整方案](./0、生产集成完整方案.md)**。本章速查用。

## 1、选型

| 场景 | 建议 |
| ---- | ---- |
| Boot 3 + 新工程 | **Flowable 7** |
| 老 Activiti 6 项目 | 维持 Activiti 或评估迁 Flowable |
| 简单订单状态 | 状态机即可，不必上 BPMN |
| 多角色审批、要审计 | BPMN 引擎 |

## 2、Service 速记

Repository → 定义 | Runtime → 实例 | Task → 待办 | History → 轨迹

## 3、集成检查

- [ ] JWT Filter 已恢复 SecurityContext；`applyUserId` 与当前用户一致  
- [ ] 启动流程写入 applyUserId  
- [ ] 待办查询含 candidate  
- [ ] complete 前 canHandle  
- [ ] businessKey 关联业务表  
- [ ] 异步节点已开 executor
