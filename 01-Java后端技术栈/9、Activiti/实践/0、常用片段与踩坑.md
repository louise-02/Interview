## 1、组名与角色映射

```java
public Collection<String> resolveGroups(Authentication auth) {
    return auth.getAuthorities().stream()
        .map(GrantedAuthority::getAuthority)
        .map(a -> a.startsWith("ROLE_") ? a.substring(5).toLowerCase() : a)
        .toList();
}
```

BPMN `candidateGroups="dept_manager"` 必须能映射到这里。

## 5、常见踩坑

| 问题 | 处理 |
| ---- | ---- |
| 改 BPMN 后老单异常 | 老实例绑旧版本；新单走新 deployment |
| complete 报 task null | taskId 错或已完成 |
| candidate 看不到待办 | 组名不一致；只查了 assignee |
| 中文乱码 | FlowableConfig 设宋体 |
| 异步节点不执行 | `async-executor-activate: false` |
| Job 里 NPE 取用户 | 异步线程无 SecurityContext，见 [5、与SpringSecurity集成](../5、与SpringSecurity集成.md) §6 |
| 与业务事务不一致 | Delegate 里避免长事务 + 先发 MQ |

## 6、Activiti 包名对照

| Flowable | Activiti |
| -------- | -------- |
| `org.flowable.engine.RuntimeService` | `org.activiti.engine.RuntimeService` |
| `flowable:delegateExpression` | `activiti:delegateExpression` |

BPMN xmlns 与扩展命名空间随引擎而变，结构相同。
