# 1、架构与请求流程

## 1、核心组件

| 组件 | 作用 |
| ---- | ---- |
| **DispatcherServlet** | 前端控制器，统一入口 |
| **HandlerMapping** | 请求 → Handler（Controller 方法） |
| **HandlerAdapter** | 调用 Handler（处理 @RequestMapping 等） |
| **HandlerInterceptor** | 拦截器链 |
| **ViewResolver** | 逻辑视图 → 物理视图（REST 常直接 MessageConverter） |
| **HandlerExceptionResolver** | 异常 → 响应 |

## 2、一次请求流程

```
HTTP 请求
  → Filter 链（Servlet 规范）
  → DispatcherServlet
  → HandlerMapping 找 Handler
  → HandlerInterceptor.preHandle
  → HandlerAdapter 执行 Controller 方法
  → 返回 ModelAndView 或 @ResponseBody 对象
  → HandlerInterceptor.postHandle
  → HttpMessageConverter 写 JSON（@RestController）
  → HandlerInterceptor.afterCompletion
  → HTTP 响应
```

## 3、RESTful 与注解

| 注解 | 说明 |
| ---- | ---- |
| `@RestController` | `@Controller` + `@ResponseBody` |
| `@GetMapping` / `@PostMapping` 等 | HTTP 方法 + 路径 |
| `@PathVariable` | URL 路径变量 |
| `@RequestParam` | 查询参数 |
| `@RequestBody` | JSON 请求体 |
| `@RequestHeader` | 请求头 |

## 4、HttpMessageConverter

将请求体反序列化为 Java 对象、将返回值序列化为 JSON/XML。

Boot 默认 **Jackson** 处理 `application/json`。

## 5、常见面试题

**1. Spring MVC 和 Servlet 关系？**

DispatcherServlet 是 Servlet；MVC 在其上封装映射、适配、视图、异常。

**2. 404 是在哪一步？**

HandlerMapping 找不到 Handler；或资源静态映射未配置。

**3. @Controller 和 @RestController？**

后者类级别 @ResponseBody，方法返回值直接写响应体。
