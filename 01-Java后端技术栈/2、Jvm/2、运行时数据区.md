# 2、运行时数据区

JVM 在运行期间管理的内存区域。HotSpot 中按**线程共享**与**线程私有**划分。

## 1、总览

| 区域 | 线程 | 作用 | 异常 |
| ---- | ---- | ---- | ---- |
| **程序计数器** | 私有 | 当前线程执行的字节码行号 | 唯一不会 OOM 的区域 |
| **虚拟机栈** | 私有 | Java 方法调用：栈帧、局部变量、操作数栈 | `StackOverflowError` / `OutOfMemoryError` |
| **本地方法栈** | 私有 | Native 方法调用 | 同上 |
| **堆** | 共享 | 对象实例、数组 | `OutOfMemoryError: Java heap space` |
| **方法区** | 共享 | 类元信息、常量、静态变量、JIT 代码 | JDK7 及以前 PermGen OOM；JDK8+ Metaspace OOM |
| **直接内存** | — | NIO DirectBuffer、MappedByteBuffer 等 | 受 `-XX:MaxDirectMemorySize` 限制 |

```
        线程1          线程2
    ┌─────────┐    ┌─────────┐
    │ PC 寄存器 │    │ PC 寄存器 │
    │ 虚拟机栈  │    │ 虚拟机栈  │
    │本地方法栈 │    │本地方法栈 │
    └────┬────┘    └────┬────┘
         │              │
    ═════╪══════════════╪═════  线程共享
         │    堆 Heap   │
         │ 方法区/元空间  │
         │  (运行时常量池) │
    ═══════════════════════
         直接内存（堆外，逻辑上独立）
```

## 2、程序计数器（PC Register）

- 当前线程所执行字节码的**行号指示器**（Native 方法时为 undefined）。
- 线程切换时用于**恢复执行位置**。
- 规范中**唯一**没有定义 `OutOfMemoryError` 的区域。

## 3、虚拟机栈

每个 Java 方法执行对应一个**栈帧（Stack Frame）**，入栈/出栈与方法调用同步。

### 3.1 栈帧结构

| 部分 | 说明 |
| ---- | ---- |
| **局部变量表** | 方法参数 + 方法内局部变量；Slot 为基本单位，long/double 占 2 个 Slot |
| **操作数栈** | 计算中间结果，基于栈的执行引擎工作区 |
| **动态链接** | 指向运行时常量池中当前方法的引用，支持动态绑定 |
| **方法返回地址** | 正常/异常退出后回到的 PC 位置 |

局部变量表大小在编译期由 `Code` 属性的 `max_locals` 确定，运行期不变。

```java
public static int add(int a, int b) {
    return a + b;
}
// 典型字节码：iload_0 → iload_1 → iadd → ireturn
```

### 3.2 栈相关异常

- **StackOverflowError**：栈深度超限（如无限递归）。
- **OutOfMemoryError**：无法扩展栈（少见，多与线程创建过多有关）。

`-Xss` 设置每个线程栈大小（默认平台相关，Linux x64 常见 1MB）。

## 4、本地方法栈

与虚拟机栈类似，服务于 **Native 方法**（C/C++ 实现）。HotSpot 中常将本地方法栈与虚拟机栈合二为一实现。

## 5、堆（Heap）

**几乎所有对象实例和数组**在堆上分配（逃逸分析优化后少量可在栈上分配，见第 3 章）。

### 5.1 分代结构（经典 HotSpot）

```
┌──────────────────────────────────────────┐
│                  堆                       │
│  ┌──────────── Young ────────────┐       │
│  │ Eden │ S0 │ S1 │  (Survivor)  │       │
│  └────────────────────────────────┘       │
│  ┌──────────── Old / Tenured ──────────┐ │
│  └─────────────────────────────────────┘ │
└──────────────────────────────────────────┘
```

- **Young**：新对象优先在 Eden 分配；Minor GC 后存活对象在 Survivor 间复制，年龄达阈值进入 Old。
- **Old**：长期存活对象；Major GC / Full GC 主要回收区域。

JDK 8 默认：**Parallel GC** 或 **G1**（JDK 9+ 默认 G1）时堆布局略有不同，G1 以 Region 为单位（见第 4 章）。

### 5.2 堆参数（常用）

| 参数 | 含义 |
| ---- | ---- |
| `-Xms` | 堆初始大小 |
| `-Xmx` | 堆最大大小（建议与 `-Xms` 相同，避免动态扩缩） |
| `-Xmn` | 年轻代大小（或用 `-XX:NewRatio`） |
| `-XX:SurvivorRatio=8` | Eden : Survivor = 8:1（两个 Survivor 各 1 份） |

## 6、方法区与方法区演进

存储：**类信息**（字段、方法、访问标志）、**运行时常量池**、**静态变量**（JDK 7 起部分移至堆）、**JIT 编译后的代码**（JDK 8 在 Code Cache）。

| JDK 版本 | 实现 | 说明 |
| -------- | ---- | ---- |
| ≤6 | 永久代 PermGen | 与方法区概念重叠，大小固定易 OOM |
| 7 | 永久代 + 变化 | 字符串常量池、静态变量移到堆 |
| ≥8 | **元空间 Metaspace** | 使用本地内存，默认仅受物理内存限制 |

元空间常用参数：

- `-XX:MetaspaceSize`：初始阈值，达到触发 GC。
- `-XX:MaxMetaspaceSize`：上限，防止无限增长。

**运行时常量池**：Class 文件常量池的运行时版本，存放字面量与符号引用，类加载后进入方法区/元空间。与 **字符串常量池（String Table，在堆）** 区别见 [9、字符串与常量池](./9、字符串与常量池.md)。

### 6.1 Code Cache

JIT 编译后的**本地机器码**存放在 **Code Cache**（非堆、非元空间，独立区域）。

- 过小 → JIT 停止编译，性能下降。
- `-XX:ReservedCodeCacheSize`、`-XX:InitialCodeCacheSize`
- 分段：`-XX:+SegmentedCodeCache`（C1/C2/non-nmethod）

## 7、TLAB 详解

**Thread Local Allocation Buffer**：Eden 中每个线程私有缓冲区，**bump-the-pointer** 分配，无锁。

| 参数 | 含义 |
| ---- | ---- |
| `-XX:+UseTLAB` | 默认开启 |
| `-XX:TLABSize` | 手动指定 TLAB 大小 |
| `-XX:ResizeTLAB` | 动态调整 |

TLAB 用尽 → 在 Eden **同步**分配或触发 Minor GC。

## 8、直接内存

并非 JVM 规范中的运行时数据区，但常与 JVM 一起调优。

- **NIO `DirectByteBuffer`**：减少堆与 Native 堆之间的拷贝。
- 分配受 **`MaxDirectMemorySize`** 限制，默认约等于 `-Xmx`。
- 泄漏表现：`OutOfMemoryError: Direct buffer memory`。

## 9、JDK 7 / 8 内存结构变化（面试常问）

| 内容 | JDK 6 | JDK 7 | JDK 8+ |
| ---- | ----- | ----- | ------ |
| 字符串常量池 | 永久代 | **堆** | 堆 |
| 静态变量 | 永久代 | **堆** | 堆 |
| 类元数据 | 永久代 | 永久代 | **元空间（本地内存）** |

## 10、线程私有 vs 共享 — 小结

| 私有 | 共享 |
| ---- | ---- |
| PC、虚拟机栈、本地方法栈 | 堆、方法区/元空间、运行时常量池 |

**局部变量**在栈的局部变量表中；**成员变量**在堆（实例）或方法区/元空间（static）。
