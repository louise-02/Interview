# 9、字符串与常量池

## 1、三种「常量池」别混

| 名称 | 位置 | 内容 |
| ---- | ---- | ---- |
| **Class 文件常量池** | `.class` 文件中 | 字面量、符号引用（编译期） |
| **运行时常量池** | 方法区 / 元空间 | Class 加载后，Class 常量池的运行时副本 |
| **字符串常量池（String Table）** | **堆**（JDK 7+） | 字符串字面量、`intern()` 驻留 |

```
"hello" 字面量
  → javac 写入 Class 常量池
  → 类加载进入运行时常量池
  → 若需驻留，在 String Table 中找/建唯一实例
```

## 2、String 创建方式

```java
String s1 = "abc";              // 字面量，可能进 String Table
String s2 = "abc";              // 同一引用（池中复用）
String s3 = new String("abc");  // 堆上新对象，≠ s1（通常）
String s4 = s3.intern();        // 池中引用，s4 == s1 为 true
```

**`==` vs `equals`**

- `==`：引用地址。
- `equals`：字符序列内容。

## 3、intern() 机制

```java
String s = new String("java").intern();
```

- JDK 6：`intern()` 把引用放入**永久代**中的 String Table（永久代满易 OOM）。
- **JDK 7+**：String Table 在**堆**，`intern()` 只在池中存**引用**，不在永久代/元空间复制一份字符数组。

**JDK 7+ 行为**

1. 若池中已有相同内容的 String，返回池中引用。
2. 若无，将堆上该 String 的引用加入 String Table 并返回（JDK 7+）；或复制一份入池（历史版本差异以当前 JDK 为准，HotSpot 7+ 为引用入池）。

**慎用**：大量 `intern()` 可能撑大 String Table（`-XX:StringTableSize`），或 intern 了巨型字符串占堆。

## 4、编译期常量折叠

```java
final String A = "hello";
final String B = "hello";
String C = "hel" + "lo";       // 编译期合并为 "hello"
final String D = "hel";
String E = D + "lo";           // 编译期可折叠为 "hello"（D 是常量）
String F = new String("hel") + "lo"; // 运行期拼接，新对象
```

`+` 拼接：编译期能确定则折叠；否则生成 `StringBuilder` / `invokedynamic`（JDK 9+ `makeConcatWithConstants`）。

## 5、JDK 6 / 7 / 8 字符串相关变化

| 版本 | String Table | 说明 |
| ---- | ------------ | ---- |
| JDK 6 | 永久代 | `intern()` 易 PermGen OOM |
| JDK 7 | 移到堆 | 减轻永久代压力 |
| JDK 8+ | 堆 | 与元空间分离，只关心堆与 StringTableSize |

**静态变量**：JDK 7 起随 Class 对象在堆；字符串字面量引用在 String Table。

## 6、String 底层结构变化

| JDK | 内部存储 |
| --- | -------- |
| ≤8 | `char[]` |
| 9+ | `byte[]` + `coder`（Latin1 / UTF-16），节省纯 ASCII 空间 |

对 JVM 面试：知道 **9 起 compact strings** 即可，不影响常量池逻辑。

## 7、常见面试题

**1. `String s = new String("a") + new String("b");` 创建几个对象？**

至少：`"a"`、`"b"` 可能已在池中；拼接过程 `StringBuilder` / 中间对象；`new String` 各 1；最终 `ab` 字符串对象。精确个数与 JDK、是否已 intern 有关，答「多个，含字面量与拼接中间对象」即可。

**2. 字符串常量池在哪里？**

JDK 7+ 在**堆**上的 String Table。

**3. 什么情况下用 intern()？**

重复极多、内容有限的字符串键（如枚举式短字符串）；避免滥用。

**4. `Integer` 缓存和 String 池一样吗？**

不同。`-128~127` 的 `Integer` 有 **IntegerCache**（堆上对象），与 String Table 无关。
