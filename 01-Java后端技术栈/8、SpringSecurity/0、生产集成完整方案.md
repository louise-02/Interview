# 生产集成完整方案

**Boot 3 + Security 6 + JWT 无状态 + 数据库用户 + 方法级权限** 的单体/微服务业务侧标准集成。  
先按本章把**类、配置、职责**搭齐；Filter 为什么在前面、JWT 怎么验，见 [1～6 章](#10、原理深入学习阅读顺序)。

---

## 1、方案说明

| 项 | 选型 |
| -- | ---- |
| 框架 | Spring Boot 3.x、Spring Security 6.x、JDK 17+ |
| 认证 | 用户名密码登录 → 签发 **JWT**；后续请求 `Authorization: Bearer` |
| Session | **无**（`STATELESS`） |
| 用户来源 | 数据库 + `UserDetailsService` |
| 密码 | **BCrypt** |
| 授权 | URL 粗粒度 + **`@PreAuthorize`** 细粒度 |
| CSRF | REST + JWT 场景 **关闭** |

微服务时 Gateway 可统一验 Token（见 [Gateway 实践](../7、SpringCloud/实践/3、Gateway鉴权与Feign透传Token.md)）；**业务服务仍建议保留本章 Filter**，或采用零信任双验。

---

## 2、请求链路（先建立整体印象）

```
POST /api/auth/login  (白名单)
  → AuthController
  → AuthenticationManager + UserDetailsService + PasswordEncoder
  → 签发 JWT 返回

GET /api/xxx  (需登录)
  → JwtAuthenticationFilter：解析 Bearer，写入 SecurityContext
  → AuthorizationFilter：URL 是否允许
  → Controller
  → @PreAuthorize（若有）：方法是否允许
```

## 4、包结构与类职责一览

```
com.example.xxx
├── config
│   ├── SecurityConfig.java           # 核心：Filter 链、白名单、401/403、CORS
│   └── MethodSecurityConfig.java     # 开启 @PreAuthorize（也可合并进 SecurityConfig）
├── security
│   ├── JwtProperties.java            # 读取 jwt.secret / expire
│   ├── JwtTokenService.java          # 签发、解析、校验 JWT
│   ├── JwtAuthenticationFilter.java  # 每个请求：Bearer → SecurityContext
│   ├── LoginUser.java                # 实现 UserDetails，携带 userId 等
│   └── SecurityUtils.java            # 业务里取当前用户
├── service
│   └── DbUserDetailsService.java     # 按用户名查库 → LoginUser
└── controller
    └── AuthController.java           # 登录、/me、可选 refresh
```

| 类 | 做什么 |
| -- | ------ |
| **SecurityConfig** | 定义 **`SecurityFilterChain`**：哪些 URL 放行、是否无 Session、是否关 CSRF、注册 JWT Filter、未登录/无权限返回 JSON |
| **MethodSecurityConfig** | `@EnableMethodSecurity`，让 **`@PreAuthorize`** 生效 |
| **JwtProperties** | 绑定 `application.yml` 里密钥、过期时间，避免硬编码 |
| **JwtTokenService** | 登录成功后 **createToken**；Filter 里 **parseUsername / validate** |
| **JwtAuthenticationFilter** | 在 UsernamePasswordAuthenticationFilter **之前**，从 Header 取 Token，还原 `Authentication` |
| **DbUserDetailsService** | Spring Security 查用户入口：用户名 → 库表 → **LoginUser**（含角色/权限） |
| **LoginUser** | 当前登录用户在 Security 里的形态；业务通过它拿 userId |
| **SecurityUtils** | 静态方法：`getUserId()`、`getUsername()`，避免到处写 `SecurityContextHolder` |
| **AuthController** | **唯一**走密码校验的 HTTP 入口；其它接口只认 JWT |


启动类加 `@EnableConfigurationProperties(JwtProperties.class)`，Spring 才会注入该配置类。

### 6.2 JwtTokenService

```java
@Service
public class JwtTokenService {

    private final JwtProperties props;

    // 登录成功后调用：把用户名写入 Token，并设置签发/过期时间
    public String createToken(UserDetails user) {
        Instant now = Instant.now();
        return Jwts.builder()
            .setSubject(user.getUsername())   // 存用户名，Filter 里 parse 出来再查库
            .setIssuedAt(Date.from(now))      // 签发时间
            .setExpiration(Date.from(now.plusSeconds(props.getExpireSeconds())))  // 过期时间
            .signWith(Keys.hmacShaKeyFor(props.getSecret().getBytes(StandardCharsets.UTF_8)),
                SignatureAlgorithm.HS256)     // HS256 对称签名，与 Gateway 验签密钥需一致
            .compact();
    }

    // Filter 里从 Bearer Token 解析出用户名
    public String parseUsername(String token) {
        return parser().parseClaimsJws(token).getBody().getSubject();
    }

    private JwtParser parser() {
        return Jwts.parserBuilder()
            .setSigningKey(Keys.hmacShaKeyFor(props.getSecret().getBytes(StandardCharsets.UTF_8)))
            .build();
    }
}
```

### 6.3 JwtAuthenticationFilter

```java
// 每个 HTTP 请求执行一次：从 Header 取 JWT，还原当前登录用户到 SecurityContext
@Component
public class JwtAuthenticationFilter extends OncePerRequestFilter {

    private final JwtTokenService jwtTokenService;
    private final UserDetailsService userDetailsService;

    @Override
    protected void doFilterInternal(HttpServletRequest request, HttpServletResponse response,
                                    FilterChain chain) throws ServletException, IOException {
        // 读 Authorization: Bearer xxx
        String auth = request.getHeader(HttpHeaders.AUTHORIZATION);
        if (auth != null && auth.startsWith("Bearer ")) {
            String token = auth.substring(7);
            try {
                String username = jwtTokenService.parseUsername(token);
                // 仅当 Context 里还没有用户时才写入，避免覆盖已有认证
                if (username != null
                    && SecurityContextHolder.getContext().getAuthentication() == null) {
                    // 按用户名查库，拿到角色/权限
                    UserDetails user = userDetailsService.loadUserByUsername(username);
                    var authentication = new UsernamePasswordAuthenticationToken(
                        user, null, user.getAuthorities());  // principal=LoginUser，credentials 置空
                    authentication.setDetails(
                        new WebAuthenticationDetailsSource().buildDetails(request));  // 记录 IP、SessionId 等
                    // 写入当前线程，后续 Controller、@PreAuthorize 都从这里取用户
                    SecurityContextHolder.getContext().setAuthentication(authentication);
                }
            } catch (JwtException ignored) {
                // Token 过期、篡改、格式错误：不写入 Context，后面 AuthorizationFilter 返回 401
            }
        }
        chain.doFilter(request, response);  // 继续走 Filter 链
    }
}
```

**每请求都会查角色/权限表吗？**  
是的。上面 Filter 在**每个带 Token 的请求**里都会调 `loadUserByUsername` → `loadAuthorities`，Token 里只存了用户名，权限每次从库（或缓存）加载。好处是改角色后下次请求即生效；缺点是 QPS 高时要优化：

| 做法 | 说明 |
| ---- | ---- |
| **缓存**（最常见） | `@Cacheable` + Redis，见 [17、SpringCache缓存](../5、SpringBoot/实践/17、SpringCache缓存.md)（Redis 先配 [16、Redis集成](../5、SpringBoot/实践/16、Redis集成.md)） |
| **权限写进 JWT** | Token 里带 `authorities` claim，请求只验签不查库；改权限要等 Token 过期或强制下线 |
| **接受查库** | 管理后台、QPS 不高时直接查库最简单 |

登录那一次也会查库（`AuthenticationManager.authenticate`），与 Filter 里是同一套 `UserDetailsService`。

**缓存优化**：在 `loadUserByUsername` 上加 `@Cacheable`，改角色/权限时 `@CacheEvict`。见 **[17、SpringCache缓存](../5、SpringBoot/实践/17、SpringCache缓存.md)** §7；Redis 连接见 [16、Redis集成](../5、SpringBoot/实践/16、Redis集成.md)。§6.4 方法体不用改。

### 6.4 LoginUser + DbUserDetailsService

角色、权限在库里分表存，加载时合并进**同一个** `authorities`（见下方 `loadAuthorities`）。表关系常见：`sys_user → sys_user_role → sys_role → sys_role_permission → sys_permission`。高 QPS 时在 `loadUserByUsername` 上加 `@Cacheable`，见 [17、SpringCache缓存](../5、SpringBoot/实践/17、SpringCache缓存.md)。

```java
// Spring Security 里的「当前用户」形态，业务层可强转为 LoginUser 取 userId
@Getter
public class LoginUser implements UserDetails {
    private final Long userId;
    private final String username;
    private final String password;       // 登录后接口一般不再用，但 UserDetails 接口要求有
    private final boolean enabled;       // false 时账号不可用
    private final Collection<? extends GrantedAuthority> authorities;  // ROLE_* 与 order:approve 混在同一 List

    // 全参构造；实现 getPassword/getUsername/isEnabled/getAuthorities/isAccountNonLocked 等
}

// Spring Security 查用户的唯一入口：登录、JWT Filter 解析用户名后都会调这里
@Service
public class DbUserDetailsService implements UserDetailsService {

    @Resource
    private SysUserMapper userMapper;
    @Resource
    private SysRoleMapper roleMapper;            // 按 userId 查角色
    @Resource
    private SysPermissionMapper permissionMapper; // 按 userId 查权限（或 selectByRoleIds）

    @Override
    public UserDetails loadUserByUsername(String username) {
        SysUser u = userMapper.selectByUsername(username);
        if (u == null) throw new UsernameNotFoundException(username);
        return new LoginUser(u.getId(), u.getUsername(), u.getPassword(), u.isEnabled(),
            loadAuthorities(u.getId()));
    }

    // 角色 + 权限 → 同一个 List<GrantedAuthority>
    private List<GrantedAuthority> loadAuthorities(Long userId) {
        List<GrantedAuthority> auths = new ArrayList<>();

        for (SysRole role : roleMapper.selectByUserId(userId)) {
            auths.add(new SimpleGrantedAuthority("ROLE_" + role.getCode()));
            // ADMIN → ROLE_ADMIN，供 hasRole("ADMIN") 使用
        }

        for (SysPermission perm : permissionMapper.selectByUserId(userId)) {
            auths.add(new SimpleGrantedAuthority(perm.getCode()));
            // order:approve，供 hasAuthority('order:approve')；不要加 ROLE_ 前缀
        }

        // 合并结果示例：[ ROLE_USER, ROLE_DEPT_MANAGER, order:view, order:approve ]
        return auths;
    }
}
```

注册/改密入库时必须 **`passwordEncoder.encode(raw)`**，禁止明文存库。

### 6.5 SecurityConfig（最重要）

```java
// 常用 import（按需补全）：
// org.springframework.security.web.* / config.annotation.* / crypto.*
// org.springframework.http.MediaType / jakarta.servlet.http.HttpServletResponse

@Configuration
@EnableWebSecurity          // 启用 Spring Security Web 能力
@EnableMethodSecurity       // 启用 @PreAuthorize、@PostAuthorize 等方法级鉴权
@RequiredArgsConstructor
public class SecurityConfig {

    private final JwtAuthenticationFilter jwtAuthenticationFilter;

    @Bean
    SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
        http
            // 关闭 CSRF：前后端分离 + JWT 无 Cookie 场景不需要；若用 Cookie Session 则不要关
            .csrf(csrf -> csrf.disable())
            // 启用 CORS，具体规则见下方 corsConfigurationSource Bean
            .cors(Customizer.withDefaults())
            // 无 Session：不创建 HttpSession，纯 JWT 无状态
            .sessionManagement(s -> s.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
            // URL 级授权（粗粒度），细粒度用 @PreAuthorize
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/api/auth/**").permitAll()       // 登录等接口放行
                .requestMatchers("/actuator/health").permitAll()   // 健康检查，生产仅暴露必要端点
                .requestMatchers("/api/admin/**").hasRole("ADMIN") // 需要 ROLE_ADMIN
                .anyRequest().authenticated())                     // 其余接口必须已登录
            // 未登录 / 无权限时返回 JSON，避免 302 跳登录页（前后端分离必配）
            .exceptionHandling(ex -> ex
                .authenticationEntryPoint(jsonEntryPoint(401, "未登录或 Token 无效"))
                .accessDeniedHandler(jsonDenied(403, "无权限")))
            // 关闭表单登录页，登录走 AuthController + JWT
            .formLogin(form -> form.disable())
            // 关闭浏览器弹窗式 Basic 认证
            .httpBasic(basic -> basic.disable())
            // 在用户名密码 Filter 之前插入 JWT Filter，优先用 Token 识别用户
            .addFilterBefore(jwtAuthenticationFilter, UsernamePasswordAuthenticationFilter.class);
        return http.build();
    }

    // 密码加密/校验（注册、登录 AuthenticationManager 内部会用）
    @Bean
    PasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder();
    }

    // 供 AuthController 登录时 authenticate() 使用
    @Bean
    AuthenticationManager authenticationManager(AuthenticationConfiguration c) throws Exception {
        return c.getAuthenticationManager();
    }

    // 跨域：允许前端域名访问 API；生产建议改成具体域名，不要用 *
    @Bean
    CorsConfigurationSource corsConfigurationSource() {
        CorsConfiguration cfg = new CorsConfiguration();
        cfg.setAllowedOriginPatterns(List.of("*"));   // 生产改为 List.of("https://your-frontend.com")
        cfg.setAllowedMethods(List.of("*"));          // GET/POST/PUT/DELETE/OPTIONS
        cfg.setAllowedHeaders(List.of("*"));          // 含 Authorization
        cfg.setAllowCredentials(true);                // 若前端带 Cookie 需 true；纯 Bearer 也可 true
        UrlBasedCorsConfigurationSource source = new UrlBasedCorsConfigurationSource();
        source.registerCorsConfiguration("/**", cfg);
        return source;
    }

    // 401：没 Token、Token 无效/过期 → 未认证
    private AuthenticationEntryPoint jsonEntryPoint(int code, String msg) {
        return (req, resp, e) -> {
            resp.setStatus(HttpServletResponse.SC_UNAUTHORIZED);
            resp.setContentType(MediaType.APPLICATION_JSON_VALUE);
            resp.getWriter().write("{\"code\":" + code + ",\"msg\":\"" + msg + "\"}");
        };
    }

    // 403：已登录但角色/权限不够 → 已认证无授权
    private AccessDeniedHandler jsonDenied(int code, String msg) {
        return (req, resp, e) -> {
            resp.setStatus(HttpServletResponse.SC_FORBIDDEN);
            resp.setContentType(MediaType.APPLICATION_JSON_VALUE);
            resp.getWriter().write("{\"code\":" + code + ",\"msg\":\"" + msg + "\"}");
        };
    }
}
```

**SecurityConfig 一件事**：把 Filter 链、白名单、无 Session、401/403 JSON、CORS、JWT Filter 注册全部配齐。

### 6.6 AuthController

```java
@RestController
@RequestMapping("/api/auth")
@RequiredArgsConstructor
public class AuthController {

    private final AuthenticationManager authenticationManager;
    private final JwtTokenService jwtTokenService;

    // 唯一走「用户名+密码」校验的接口；成功后返回 JWT，后续请求只带 Token
    @PostMapping("/login")
    public Result login(@RequestBody LoginRequest req) {
        var token = new UsernamePasswordAuthenticationToken(req.getUsername(), req.getPassword());
        // 内部会调 UserDetailsService + PasswordEncoder 校验密码
        Authentication auth = authenticationManager.authenticate(token);
        SecurityContextHolder.getContext().setAuthentication(auth);
        String jwt = jwtTokenService.createToken((UserDetails) auth.getPrincipal());
        return Result.ok(Map.of("token", jwt));
    }

    // 冒烟测试：验证 JWT Filter + SecurityContext 是否正常
    @GetMapping("/me")
    public Result me(@AuthenticationPrincipal LoginUser user) {
        return Result.ok(Map.of("userId", user.getUserId(), "username", user.getUsername()));
    }
}
```

### 6.7 SecurityUtils（业务层使用）

```java
// 业务代码取当前用户，避免到处写 SecurityContextHolder
public final class SecurityUtils {
    public static LoginUser getLoginUser() {
        Authentication a = SecurityContextHolder.getContext().getAuthentication();
        if (a != null && a.getPrincipal() instanceof LoginUser u) return u;
        return null;
    }
    public static Long getUserId() {
        LoginUser u = getLoginUser();
        return u == null ? null : u.getUserId();
    }
}
```

## 7、接口约定

| 接口 | 鉴权 | 说明 |
| ---- | ---- | ---- |
| `POST /api/auth/login` | 无 | body: username/password；返回 `{ token }` |
| `GET /api/auth/me` | Bearer | 验证 Token 链路是否通 |
| 其它 `/api/**` | Bearer | Header: `Authorization: Bearer <token>` |

| HTTP | 含义 |
| ---- | ---- |
| 401 | 没 Token、Token 无效或过期 |
| 403 | 已登录，角色/权限不够 |

## 8、上线检查清单

- [ ] `jwt.secret` 在配置中心，足够长，不进 Git  
- [ ] 生产关闭 Swagger 或加鉴权；Actuator 仅暴露 health  
- [ ] 用户表密码 BCrypt 存储  
- [ ] 401/403 返回 JSON，不是跳转登录页  
- [ ] 前端跨域：Security + CORS 同时配（见 [跨域CORS](../5、SpringBoot/实践/8、跨域CORS.md)）  
- [ ] 日志不打 Token 明文
