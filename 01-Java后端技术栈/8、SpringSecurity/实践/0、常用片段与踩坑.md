## 1、SecurityUtils 取当前用户

```java
public final class SecurityUtils {

    private SecurityUtils() {}

    public static Authentication getAuthentication() {
        return SecurityContextHolder.getContext().getAuthentication();
    }

    public static String getUsername() {
        Authentication auth = getAuthentication();
        return auth == null ? null : auth.getName();
    }

    public static LoginUser getLoginUser() {
        Authentication auth = getAuthentication();
        if (auth != null && auth.getPrincipal() instanceof LoginUser user) {
            return user;
        }
        return null;
    }

    public static Long getUserId() {
        LoginUser user = getLoginUser();
        return user == null ? null : user.getUserId();
    }
}
```

## 3、@Async 丢失 SecurityContext

```java
@Bean
TaskExecutor taskExecutor() {
    ThreadPoolTaskExecutor executor = new ThreadPoolTaskExecutor();
    executor.initialize();
    return new DelegatingSecurityContextTaskExecutor(executor);
}
```

## 4、WebSocket 鉴权

`@ServerEndpoint` 握手时从 query/header 取 Token，在 `@OnOpen` 里校验并绑定用户（见 [SpringBoot/实践/11、WebSocket集成](../../5、SpringBoot/实践/11、WebSocket集成.md)）。  
Security 的 JWT Filter 默认不过 WebSocket 升级路径，需单独处理或走 Spring WebSocketHandler + Interceptor。

## 6、常见坑速查

| 现象 | 处理 |
| ---- | ---- |
| 403 on OPTIONS | Security 开启 `http.cors()` + CorsConfigurationSource |
| 登录成功仍 401 | 后续请求未带 `Authorization: Bearer` |
| `ROLE_` 重复 | DB 存 `ADMIN`，代码 `hasRole("ADMIN")`；存了 `ROLE_ADMIN` 则 `hasAuthority("ROLE_ADMIN")` |
| `@PreAuthorize` 不生效 | 缺少 `@EnableMethodSecurity`；方法非 public；同类内部自调用绕过 AOP |
| 密码永远不对 | 注册时未 `encode`；或用了 `{noop}` 前缀测试遗留到生产 |
| 升级 Boot3 编译失败 | `javax` → `jakarta`；Security 配置整体改写 |
| 循环依赖 | SecurityConfig 与 UserDetailsService 互依赖 → `@Lazy` 或拆分配置类 |
