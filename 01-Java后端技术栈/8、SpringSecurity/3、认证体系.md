# 3、认证体系

> 完整类清单与 `DbUserDetailsService`、`AuthController` 模板见 **[0、生产集成完整方案](./0、生产集成完整方案.md)**。

## 1、认证流程（DAO 模式）

```
用户名/密码
  → AuthenticationManager
  → DaoAuthenticationProvider
  → UserDetailsService.loadUserByUsername(username)
  → PasswordEncoder.matches(输入密码, 库中 hash)
  → 成功：UsernamePasswordAuthenticationToken 写入 SecurityContext
```

## 2、UserDetailsService 实现

```java
@Service
public class DbUserDetailsService implements UserDetailsService {

    @Resource
    private SysUserMapper userMapper;

    @Override
    public UserDetails loadUserByUsername(String username) {
        SysUser user = userMapper.selectByUsername(username);
        if (user == null) {
            throw new UsernameNotFoundException("用户不存在");
        }
        List<GrantedAuthority> authorities = loadAuthorities(user.getId());
        return User.builder()
            .username(user.getUsername())
            .password(user.getPassword())       // 库中 BCrypt 密文
            .authorities(authorities)
            .disabled(!user.isEnabled())
            .build();
    }

    private List<GrantedAuthority> loadAuthorities(Long userId) {
        // 查角色、权限，转成 SimpleGrantedAuthority
        // 角色建议：ROLE_ADMIN；细粒度：order:approve
        return List.of(new SimpleGrantedAuthority("ROLE_USER"));
    }
}
```

## 3、自定义 UserDetails（携带业务字段）

`User.builder()` 只有基础字段；需要 userId、部门时：

```java
public class LoginUser implements UserDetails {
    private final Long userId;
    private final String username;
    private final String password;
    private final Collection<? extends GrantedAuthority> authorities;

    // 实现 UserDetails 各方法 getUsername/getPassword/isEnabled...

    public Long getUserId() { return userId; }
}
```

业务里取当前用户：

```java
Authentication auth = SecurityContextHolder.getContext().getAuthentication();
LoginUser loginUser = (LoginUser) auth.getPrincipal();
Long userId = loginUser.getUserId();
```

或封装工具类 `SecurityUtils.getUserId()`。

## 4、JSON 登录接口（前后端分离）

不用默认 formLogin 跳转，自定义 Controller + `AuthenticationManager`：

```java
@RestController
@RequestMapping("/api/auth")
public class AuthController {

    @Resource
    private AuthenticationManager authenticationManager;
    @Resource
    private JwtTokenService jwtTokenService;

    @PostMapping("/login")
    public Result login(@RequestBody LoginRequest req) {
        UsernamePasswordAuthenticationToken token =
            new UsernamePasswordAuthenticationToken(req.getUsername(), req.getPassword());
        Authentication auth = authenticationManager.authenticate(token);
        SecurityContextHolder.getContext().setAuthentication(auth);
        String jwt = jwtTokenService.createToken(auth);
        return Result.ok(Map.of("token", jwt));
    }
}
```

注册 `AuthenticationManager` Bean：

```java
@Bean
AuthenticationManager authenticationManager(AuthenticationConfiguration config) throws Exception {
    return config.getAuthenticationManager();
}
```

## 5、登出

无 Session 时「登出」= **客户端删 Token**；服务端可选 **Token 黑名单**（Redis）或短过期时间。

有 Session 时：

```java
http.logout(logout -> logout
    .logoutUrl("/api/auth/logout")
    .logoutSuccessHandler((req, resp, auth) -> {
        resp.setStatus(200);
    }));
```

## 7、多数据源 / 多 UserDetailsService

## 8、常见坑

| 现象 | 原因 |
| ---- | ---- |
| 用户存在但登录失败 | 库中不是 BCrypt；或 `matches` 用错 |
| 角色不生效 | 应用 `hasRole("ADMIN")` 但 authority 应是 `ROLE_ADMIN` |
| 匿名访问被拦 | 白名单未 `permitAll`；或 `@PreAuthorize` 在类上 |
| 循环依赖 | `UserDetailsService` 里注入会触发 Security 初始化的 Bean → 拆模块或 `@Lazy` |
