## 怎么写新笔记

- 搞懂自动配置、Starter 原理 → 补 **知识体系** 某一章
- 项目里可抄的代码 → 在 **实践/** 新建或更新一篇（文件名带序号，正文不要重复文件名作一级标题）
- 小注解、小踩坑 → 补 [0、常用片段与踩坑](./实践/0、常用片段与踩坑.md) 对应小节
- 面试被问到且想背答案 → 补 **面试/6**

> 实践文档约定：**文件名**即主题；**正文**直接从 `# 小节名` 开始，原 `##` 提升为 `#`，原 `###` 提升为 `##`。
