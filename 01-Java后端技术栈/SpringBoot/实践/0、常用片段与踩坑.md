# Jackson 序列化 / 反序列化

## 日期转换（入参 / 出参）

`@JsonFormat` 管**出参**（对象 → JSON），`@DateTimeFormat` 管**入参**（Query / 表单 → 对象），常成对使用。

```java
public class OrderVO {
    @JsonFormat(pattern = "yyyy-MM-dd", timezone = "GMT+8")
    private LocalDate orderDate;

    @DateTimeFormat(pattern = "yyyy-MM-dd")
    private LocalDate queryDate;
}
```

| 注解 | 方向 | 作用 |
| ---- | ---- | ---- |
| `@JsonFormat` | **出参** | Jackson 写 JSON 时的日期格式 |
| `@DateTimeFormat` | **入参** | Spring MVC 绑定请求参数时的日期格式 |

**全局日期配置（application.yml）**

```yaml
spring:
  jackson:
    date-format: yyyy-MM-dd HH:mm:ss
    time-zone: GMT+8
    serialization:
      write-dates-as-timestamps: false
```

Boot 3 + `LocalDateTime` 时，`date-format` 可能不生效，需自定义 `ObjectMapper` 或字段上保留 `@JsonFormat`。

```java
@Bean
public ObjectMapper objectMapper() {
    ObjectMapper mapper = new ObjectMapper();
    mapper.registerModule(new JavaTimeModule());
    mapper.disable(SerializationFeature.WRITE_DATES_AS_TIMESTAMPS);
    mapper.setTimeZone(TimeZone.getTimeZone("GMT+8"));
    return mapper;
}
```

## 忽略 null 字段

```java
@JsonInclude(JsonInclude.Include.NON_NULL)
public class UserVO { }
```

或全局：`spring.jackson.default-property-inclusion: non_null`

## 雪花算法主键精度丢失

JS `Number` 最大安全整数为 `2^53 - 1`，雪花 ID（`Long`）超出后前端会**精度丢失**。

```java
public class OrderVO {
    @JsonFormat(shape = JsonFormat.Shape.STRING)
    private Long id;
}
```

等价写法：

```java
@JsonSerialize(using = ToStringSerializer.class)
private Long id;
```

全局处理（所有 Long 转 String）：

```java
@Bean
public Jackson2ObjectMapperBuilderCustomizer jacksonCustomizer() {
    return builder -> builder.serializerByType(Long.class, ToStringSerializer.instance)
            .serializerByType(Long.TYPE, ToStringSerializer.instance);
}
```

# 加载 classpath 下文件

| 方式 | 适用场景 |
| ---- | -------- |
| 方式一 `@Value` | 注入固定路径的 Resource 或字符串 |
| 方式二 `ClassPathResource` | Spring 推荐，代码里读流 |
| 方式三 `ResourceLoader` | 路径可配置、需统一 Resource 抽象 |
| 方式四 `ClassLoader` | 不依赖 Spring 容器，工具类 / static 方法 |

## 方式一：@Value 注入

```java
@Value("classpath:templates/email.html")
private Resource emailTemplate;

@Value("classpath:config/app.json")
private String jsonContent;   // 直接读成字符串
```

## 方式二：ClassPathResource

```java
ClassPathResource resource = new ClassPathResource("config/app.json");
try (InputStream in = resource.getInputStream()) {
    String text = new String(in.readAllBytes(), StandardCharsets.UTF_8);
}
```

## 方式三：ResourceLoader

路径可来自配置文件，适合运行时动态指定：

```java
@Resource
private ResourceLoader resourceLoader;

Resource resource = resourceLoader.getResource("classpath:config/app.json");
try (InputStream in = resource.getInputStream()) {
    // 读取内容
}
```

## 方式四：ClassLoader（纯 Java）

不依赖 Spring 容器，静态工具类中常用：

```java
// 推荐：当前线程上下文 ClassLoader
InputStream in = Thread.currentThread()
        .getContextClassLoader()
        .getResourceAsStream("config/app.json");

// 或：当前类的 ClassLoader
InputStream in2 = getClass().getClassLoader().getResourceAsStream("config/app.json");
```

**路径写法**

| 写法 | 含义 |
| ---- | ---- |
| `classpath:config/a.json` | 当前 classpath 根下 `config/a.json` |
| `classpath*:mapper/**/*.xml` | 扫描**所有 jar** 中匹配的 xml（MyBatis 常用） |
| `classpath:/config/a.json` | 与 `classpath:config/a.json` 等价 |

> classpath 资源在 jar 内**只读**；需可写目录请用 `file:` 或磁盘绝对路径。

# 配置文件优先级

## Spring Boot 单机

**命令行参数 > 操作系统环境变量 > 应用外的配置文件 > 应用内的配置文件**

| 优先级（高 → 低） | 来源 |
| :---------------- | :--- |
| 1 | 命令行 `--server.port=9090` |
| 2 | Java 系统属性 `-Dserver.port=9090` |
| 3 | 环境变量 `SERVER_PORT=9090` |
| 4 | jar 外 `./config/application.yml` |
| 5 | jar 外 `./application.yml` |
| 6 | jar 内 `classpath:application.yml` |

## 占位符 `${}`：敏感项不写死在 yml

密码、密钥等用占位符，**值来自命令行或环境变量**，jar 里只留 key 名。

```yaml
spring:
  datasource:
    username: ${db_username}
    password: ${db_password}
```

### 方式一：命令行传参（优先级高）

```bash
java -jar xx.jar --db_username=root --db_password=123456
```

Spring Boot 会把 `--db_username=root` 绑定为属性 `db_username`。

### 方式二：环境变量（适合生产直接启动 jar）

```bash
export DB_USERNAME=root
export DB_PASSWORD=123456
java -jar xx.jar
```

占位符 `${db_username}` 会匹配环境变量 **`DB_USERNAME`**（Spring **松散绑定**：小写+下划线 ↔ 大写+下划线）。

| yml 占位符 | 环境变量示例 |
| ---------- | ------------ |
| `${db_username}` | `DB_USERNAME` |
| `${db.password}` | `DB_PASSWORD` |

### 缺省值（可选）

```yaml
password: ${db_password:123456}   # 未传入时用默认值（生产慎用默认密码）
```

### 注意

| 点 | 说明 |
| -- | ---- |
| 优先级 | 命令行 `--key=value` **高于** 环境变量，见上表 |
| 不要提交真实密码 | yml 进 Git 只留 `${...}`，值在部署环境注入 |
| Docker | 用 `environment:` 或 `-e DB_PASSWORD=xxx` 同理 |
| 启动失败 | 占位符无值且未写 `:默认值` 时会报 `Could not resolve placeholder` |

---

| | bootstrap.yml | application.yml |
| -- | ------------- | ----------------- |
| 加载 | bootstrap 上下文（更早） | 主 application 上下文 |
| 用途 | 配置中心地址、应用名、拉远程配置 | 业务配置（数据源、Redis 等） |

老项目常说 **bootstrap 优先级高于 application**，指的是 bootstrap 阶段**先连配置中心、远程配置优先生效**；本地文件对比时，**application.yml 可覆盖 bootstrap 同名项**（还受 Cloud 覆盖开关影响）。

Boot 2.4+ 可用 `spring.config.import` 替代 bootstrap：

```yaml
spring:
  config:
    import: optional:nacos:order-service.yaml
```

## 接入 Spring Cloud 配置中心后

**配置中心 > 命令行参数 > 本地 application.yml > 本地 bootstrap.yml**

| 优先级（高 → 低） | 来源 |
| :---------------- | :--- |
| 1 | 配置中心（Nacos / Config Server） |
| 2 | 命令行参数 |
| 3 | 环境变量 / `-D` 系统属性 |
| 4 | 本地 `application.yml` |
| 5 | 本地 `bootstrap.yml` |

## 配置允许覆盖

控制本地配置能否覆盖远程（Spring Cloud Config Client）：

```yaml
spring:
  cloud:
    config:
      allow-override: true               # 允许本地覆盖远程
      override-none: true                # true：远程配置不可被本地覆盖
      override-system-properties: false  # false：系统属性也不覆盖远程
```

| 属性 | 含义 |
| ---- | ---- |
| `allow-override` | 是否允许本地 property 覆盖远程 |
| `override-none` | `true` 时远程配置不能被本地覆盖 |
| `override-system-properties` | 是否允许 `-D` 覆盖远程 |

# AOP / @Transactional 同类调用失效

`this.inner()` 不经过代理，切面不生效。

```java
@EnableAspectJAutoProxy(exposeProxy = true, proxyTargetClass = true)
@SpringBootApplication
public class Application { }
```

```java
@Service
public class UserServiceImpl implements UserService {
    @Transactional
    public void inner() { }

    public void outer() {
        UserServiceImpl proxy = (UserServiceImpl) AopContext.currentProxy();
        proxy.inner();
    }
}
```

| 方案 | 说明 |
| ---- | ---- |
| `AopContext.currentProxy()` | 需 `exposeProxy = true` |
| 注入自身接口 | `@Resource private UserService self;` 再 `self.inner()` |
| 拆到另一个 Bean | 推荐 |
| 编程式事务 | 见 [10、编程式事务](./10、编程式事务.md) |
