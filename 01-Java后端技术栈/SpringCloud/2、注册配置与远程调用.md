# 2、注册配置与远程调用

## 1、Nacos 注册发现

服务启动 → 向 Nacos **注册**实例（IP、端口、元数据）→ 消费者 **订阅** 服务名 → 获取健康实例列表 → **LoadBalancer** 选一个调用。

```yaml
spring:
  cloud:
    nacos:
      discovery:
        server-addr: 127.0.0.1:8848
        namespace: dev
```

**健康检查**：临时实例心跳；持久实例 CP 模式。

## 2、Nacos 配置中心

配置存 Nacos，应用 `spring.config.import=nacos:app.yaml` 或 `bootstrap` 方式拉取；支持 **动态刷新** `@RefreshScope`。

```java
@RefreshScope
@ConfigurationProperties(prefix = "order")
public class OrderConfig { }
```

## 3、OpenFeign

声明式 HTTP 客户端：

```java
@FeignClient(name = "order-service", path = "/api/order")
public interface OrderClient {
    @GetMapping("/{id}")
    Result<OrderVO> getById(@PathVariable Long id);
}
```

**原理**：JDK 动态代理 + LoadBalancer + HttpClient。

**传递 Header**：`RequestInterceptor` 透传 Token、TraceId。

**超时与重试**：`feign.client.config`、配合 Sentinel 限流。

## 4、LoadBalancer

替代 Ribbon：`@LoadBalanced RestTemplate` 或 Feign 内置；策略 RoundRobin、Random 等。

服务名 `http://order-service/api/...` 中的 `order-service` 由 LoadBalancer 解析为实例 IP:Port。

## 5、常见面试题

**1. Feign 第一次调用慢？**

懒加载客户端、DNS、连接池初始化；可 warmup 或 httpclient 连接池调优。

**2. 配置中心和本地 application 优先级？**

后加载覆盖前者；Nacos 动态刷新只影响 `@RefreshScope` / `@ConfigurationProperties` Bean。

**3. 多环境隔离？**

Nacos **namespace** + **group** + profile。
