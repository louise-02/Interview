# 1、场景引入

请假审批：500 以内组长批，500～5000 经理批，5000 以上总监批。请求沿审批链传递，**直到有人处理**；处理者不必知道完整链结构。

# 2、普通写法

```java
public void approve(LeaveRequest req) {
    if (req.getDays() <= 1) {
        leader.approve(req);
    } else if (req.getDays() <= 3) {
        manager.approve(req);
    } else {
        director.approve(req);
    }
}
```

**问题**：审批规则集中在一个方法；新增级别要改逻辑；请求发送者与处理者紧耦合。

# 3、设计模式做法

## 介绍

责任链模式（Chain of Responsibility）：使多个对象都有机会处理请求，将这些对象连成一条链，沿链传递请求直到有对象处理它。

```java
// 处理器抽象
public abstract class Approver {
    protected Approver next; // 下一个节点
    protected String name;

    public void setNext(Approver next) {
        this.next = next;
    }

    public abstract void process(LeaveRequest request);
}

// 具体处理器：能处理则处理，否则转发
public class GroupLeader extends Approver {
    public GroupLeader(String name) { this.name = name; }

    public void process(LeaveRequest req) {
        if (req.getDays() <= 1) {
            System.out.println(name + " 批准");
        } else if (next != null) {
            next.process(req); // 沿链传递
        }
    }
}

public class Manager extends Approver {
    public Manager(String name) { this.name = name; }

    public void process(LeaveRequest req) {
        if (req.getDays() <= 3) {
            System.out.println(name + " 批准");
        } else if (next != null) {
            next.process(req);
        }
    }
}

public class LeaveRequest {
    private final int days;
    public LeaveRequest(int days) { this.days = days; }
    public int getDays() { return days; }
}
```

客户端只需把请求交给链头，不必关心谁最终处理。

## 客户端调用

```java
public class Client {
    public static void main(String[] args) {
        Approver leader = new GroupLeader("组长");
        Approver manager = new Manager("经理");
        leader.setNext(manager);

        LeaveRequest req = new LeaveRequest(3);
        leader.process(req); // 从链头进入，沿链传递
    }
}
```

## 注意事项

1. 链上节点可处理也可转发。
2. 可能没有节点处理（需兜底或抛异常）。
3. 与装饰：责任链是「传递处理权」；装饰是「层层增强同一调用」。

# 4、源码中的运用

| 案例 | 说明 |
| :--- | :--- |
| Servlet `Filter` 链 | 请求依次经过多个 Filter |
| Spring MVC `HandlerInterceptor` | preHandle 链式执行 |
| Netty `ChannelPipeline` | 入站/出站处理器链 |
| MyBatis 插件 `Interceptor` 链 | 拦截 Executor 调用 |
