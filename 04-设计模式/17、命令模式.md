# 1、场景引入

智能家居：遥控器上的按钮要执行「开灯」「关灯」「调音量」。希望支持**撤销**、**宏命令（一键场景）**、**排队执行**，且触发者与执行者解耦。

# 2、普通写法

```java
public class RemoteControl {
    public void button1() { new Light().on(); }
    public void button2() { new Light().off(); }
}
```

**问题**：无法记录/撤销操作；无法组合多个操作为场景；按钮与具体设备耦合。

# 3、设计模式做法

## 介绍

命令模式（Command）：将**请求封装成对象**，从而可参数化、排队、记录日志、支持撤销。

```java
// 命令：把操作封装成对象
public interface Command {
    void execute();
    void undo();
}

public class LightOnCommand implements Command {
    private final Light light; // 接收者

    public LightOnCommand(Light light) { this.light = light; }

    public void execute() { light.on(); }
    public void undo() { light.off(); }
}

public class LightOffCommand implements Command {
    private final Light light;

    public LightOffCommand(Light light) { this.light = light; }

    public void execute() { light.off(); }
    public void undo() { light.on(); }
}

// 调用者：触发命令，并支持撤销
public class RemoteControl {
    private final List<Command> history = new ArrayList<>();

    public void press(Command cmd) {
        cmd.execute();
        history.add(cmd);
    }

    public void undo() {
        if (!history.isEmpty()) {
            history.remove(history.size() - 1).undo();
        }
    }
}
```

**宏命令**：一个 Command 内部持有多个 Command 依次 execute。

## 客户端调用

```java
public class Client {
    public static void main(String[] args) {
        Light light = new Light();
        RemoteControl remote = new RemoteControl();

        remote.press(new LightOnCommand(light));
        remote.press(new LightOffCommand(light));
        remote.undo(); // 撤销上一条命令
    }
}
```

## 注意事项

1. 解耦调用者与接收者；适合任务队列、事务性操作、Undo。
2. 命令过多时类数量增加。
3. 与策略：命令封装「一次操作/请求」；策略封装「可替换算法」。

# 4、源码中的运用

| 案例 | 说明 |
| :--- | :--- |
| `Runnable` / `Callable` | 将任务封装为对象提交线程池 |
| Spring `TransactionTemplate` | 将事务逻辑封装为回调命令 |
| IDE 撤销/重做 | 操作历史栈 |
| MQ 消息 | 请求对象化后异步执行 |
