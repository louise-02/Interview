# 1、场景引入

系统里已有 `MediaPlayer` 只能播放 MP3。现在接入第三方类 `AdvancedMediaPlayer`，接口是 `playAdvanced(type, fileName)`，和现有 `playMp3(fileName)` 不兼容。希望**不改第三方代码**，让客户端仍用统一接口播放 MP3/MP4/VLC。

# 2、普通写法

```java
public class Client {
    public void play(String type, String file) {
        if ("mp3".equals(type)) {
            new MediaPlayer().playMp3(file);
        } else {
            // 直接 new 第三方类，接口不统一
            new AdvancedMediaPlayer().playAdvanced(type, file);
        }
    }
}
```

**问题**：客户端要区分多种接口；每多一种格式就要改客户端；无法复用已有抽象。

# 3、设计模式做法

## 介绍

适配器模式（Adapter）：将一个类的接口转换成客户端期望的另一个接口，使原本不兼容的类可以协同工作。

## 类适配器 vs 对象适配器

Java 单继承，**对象适配器**更常用：持有被适配者，在目标接口方法里转发。

```java
// 目标接口：客户端只认这个
public interface MediaPlayer {
    void play(String fileName);
}

// 被适配者（第三方，不能改）
public class AdvancedMediaPlayer {
    public void playMp4(String file) { System.out.println("mp4: " + file); }
    public void playVlc(String file) { System.out.println("vlc: " + file); }
}

// 适配器：把 play() 转成第三方的 playMp4/playVlc
public class MediaAdapter implements MediaPlayer {
    private final AdvancedMediaPlayer advanced = new AdvancedMediaPlayer();
    private final String type;

    public MediaAdapter(String type) {
        this.type = type;
    }

    @Override
    public void play(String fileName) {
        if ("mp4".equals(type)) {
            advanced.playMp4(fileName);
        } else if ("vlc".equals(type)) {
            advanced.playVlc(fileName);
        }
    }
}
```

## 客户端调用

```java
public class Client {
    public static void main(String[] args) {
        // 客户端始终只调 play()，不用关心第三方接口
        MediaPlayer mp3 = new MediaPlayer(); // 原有实现
        mp3.play("song.mp3");

        MediaPlayer mp4 = new MediaAdapter("mp4");
        mp4.play("video.mp4"); // 内部转成 advanced.playMp4()

        MediaPlayer vlc = new MediaAdapter("vlc");
        vlc.play("movie.vlc");
    }
}
```

## 注意事项

1. 适合**已有类接口不兼容**、又不能改源码的场景。
2. 与装饰模式：适配器改变接口；装饰器增强功能、接口不变。
3. 与代理模式：适配器解决兼容；代理控制访问、加横切逻辑。

# 4、源码中的运用

| 案例 | 说明 |
| :--- | :--- |
| `InputStreamReader` | 字节流 → 字符流适配 |
| `Arrays.asList()` | 数组适配为 List |
| Spring MVC `HandlerAdapter` | 将不同 Controller 写法适配为统一调用 |
| Spring `WebMvcConfigurer` 相关 Adapter | 旧接口到新接口的适配 |
