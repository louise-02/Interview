# 1、场景引入

有一只羊 tom（1 岁、白色），需要再创建 10 只属性完全相同的羊。如果每只都手动 set 一遍属性，对象复杂时既繁琐又容易漏字段。

# 2、普通写法

```java
public class Sheep {
    String name;
    Integer age;
    String color;

    public Sheep(String name, Integer age, String color) {
        this.name = name;
        this.age = age;
        this.color = color;
    }
}

public class Test {
    public static void main(String[] args) {
        Sheep tom = new Sheep("tom", 1, "白色");
        Sheep copy1 = new Sheep(tom.name, tom.age, tom.color);
        Sheep copy2 = new Sheep(tom.name, tom.age, tom.color);
        // 重复 10 次...
    }
}
```

**问题**：复制时要逐个拷贝属性；对象字段多、有嵌套引用时更麻烦；无法直接拿到「运行时的当前状态」来复制。

# 3、设计模式做法

## 介绍

原型模式（Prototype）：用**原型实例**指定创建对象的种类，通过**拷贝**原型来创建新对象，无需关心创建细节。

## 代码实现

```java
// 原型：实现 Cloneable 才能 clone
public class Sheep implements Cloneable {
    String name;
    Integer age;
    String color;
    Sheep friend; // 引用类型，默认浅拷贝会共享

    public Sheep(String name, Integer age, String color) {
        this.name = name;
        this.age = age;
        this.color = color;
    }

    @Override
    public Sheep clone() {
        try {
            return (Sheep) super.clone(); // 浅拷贝
        } catch (CloneNotSupportedException e) {
            throw new AssertionError();
        }
    }
}
```

## 浅拷贝与深拷贝

| 类型 | 说明 |
| :--- | :--- |
| 浅拷贝 | 基本类型值拷贝；引用类型只拷贝地址，两个对象共享同一引用 |
| 深拷贝 | 引用类型也递归复制，互不影响 |

**深拷贝实现**

1. 重写 `clone()`，手动复制引用字段  
2. **序列化/反序列化**（推荐，通用）

```java
// 序列化深拷贝示意
ByteArrayOutputStream bos = new ByteArrayOutputStream();
new ObjectOutputStream(bos).writeObject(sheep);
Sheep deepCopy = (Sheep) new ObjectInputStream(
    new ByteArrayInputStream(bos.toByteArray())).readObject();
```

## 注意事项

1. 适合创建成本高的对象，或需要基于现有对象快速复制时。
2. 需实现 `Cloneable`，否则 `clone()` 抛异常。
3. 有引用嵌套时默认浅拷贝，要按需做深拷贝。
4. 与工厂模式：原型是「复制已有对象」；工厂是「按规则 new 新对象」。

## 客户端调用

```java
public class Client {
    public static void main(String[] args) {
        Sheep tom = new Sheep("tom", 1, "白色");
        tom.friend = new Sheep("rose", 2, "黑色");

        // 浅拷贝：friend 仍指向同一只 rose
        Sheep copy = tom.clone();

        // 深拷贝：序列化方式，friend 也是新对象
        // Sheep deepCopy = deepClone(tom);
    }
}
```

# 4、源码中的运用

| 案例 | 说明 |
| :--- | :--- |
| `Object.clone()` | JDK 原型机制基础 |
| Spring `@Scope("prototype")` | 每次 getBean 创建新实例，与 singleton 相对 |
| `BeanUtils.copyProperties()` | 属性拷贝，思想类似原型（非 clone 机制） |
| Java 反序列化 | 从字节流恢复对象，可视为另一种「复制」 |
