# 1、场景引入

要遍历 ArrayList、LinkedList、HashSet 等不同集合，希望**统一遍历方式**，又不暴露集合内部结构（数组下标、链表节点等）。

# 2、普通写法

```java
public void print(ArrayList<String> list) {
    for (int i = 0; i < list.size(); i++) {
        System.out.println(list.get(i));
    }
}

public void print(LinkedList<String> list) {
    Node node = list.head;
    while (node != null) { /* ... */ }
}
```

**问题**：每种集合一种遍历写法；客户端依赖内部实现；难以在遍历过程中统一加过滤、并发控制。

# 3、设计模式做法

## 介绍

迭代器模式（Iterator）：提供一种方法顺序访问聚合对象中的各个元素，而又**不暴露**该对象的内部表示。

```java
// 迭代器：统一遍历方式
public interface Iterator<E> {
    boolean hasNext();
    E next();
}

// 可迭代集合：提供 iterator()
public interface Iterable<E> {
    Iterator<E> iterator();
}
```

## 客户端调用

```java
public class Client {
    public static void main(String[] args) {
        List<String> list = Arrays.asList("a", "b", "c");
        Iterator<String> it = list.iterator();
        while (it.hasNext()) {
            System.out.println(it.next());
        }
        // 或增强 for，编译后等价于上面
    }
}
```

## 注意事项

1. Java 集合框架核心模式之一。
2. `Iterable` + `Iterator` 分离遍历行为与集合结构。
3. _fail-fast_ 迭代器在并发修改时抛 `ConcurrentModificationException`（`CopyOnWriteArrayList` 等除外）。

# 4、源码中的运用

| 案例 | 说明 |
| :--- | :--- |
| `java.util.Iterator` | 所有 Collection 遍历 |
| MyBatis `DefaultSqlSession` 结果集遍历 | Cursor 迭代大结果集 |
| Stream API | 内部基于 Spliterator 的迭代思想 |
| `Foreach` 增强 for | 编译器转为 Iterator 调用 |
