# 1、场景引入

系统里有些对象**全局只需要一份**：配置中心、线程池、数据库连接池、日志管理器等。如果到处 `new`，会浪费内存，还可能因为多实例导致状态不一致。

# 2、普通写法

```java
public class AppConfig {
    private Properties props = new Properties();
    // 加载配置...
}

public class Client {
    public static void main(String[] args) {
        AppConfig c1 = new AppConfig();
        AppConfig c2 = new AppConfig(); // 又加载一遍，多实例
    }
}
```

**问题**：无法保证全局唯一；重量级对象重复创建开销大；多处持有不同实例时配置可能不一致。

# 3、设计模式做法

## 介绍

单例模式（Singleton）保证一个类**只有一个实例**，并提供全局访问点（通常是静态 `getInstance()`）。

## 注意事项

1. 节省资源，适合频繁使用但不宜重复创建的对象（连接池、工具类、SessionFactory 等）。
2. 获取实例要用规定方法，不要在外部随意 `new`。
3. 多线程、反射、反序列化都可能破坏单例，生产写法要选线程安全且防破坏的方案。

## 代码实现（八种）

### 饿汉式（静态常量）

类加载时完成实例化，线程安全，但无懒加载。

```java
public class Singleton_01 {
    private static final Singleton_01 INSTANCE = new Singleton_01(); // 类加载时创建

    private Singleton_01() {} // 禁止外部 new

    public static Singleton_01 getInstance() {
        return INSTANCE;
    }
}
```

### 饿汉式（静态代码块）

与上类似，逻辑写在 static 块里。

```java
public class Singleton_02 {
    private static final Singleton_02 INSTANCE;

    static {
        INSTANCE = new Singleton_02();
    }

    private Singleton_02() {}

    public static Singleton_02 getInstance() {
        return INSTANCE;
    }
}
```

### 懒汉式（线程不安全）

有懒加载，仅适用于单线程。

```java
public class Singleton_03 {
    private static Singleton_03 instance;

    private Singleton_03() {}

    public static Singleton_03 getInstance() {
        if (instance == null) {
            instance = new Singleton_03();
        }
        return instance;
    }
}
```

### 懒汉式（同步方法）

线程安全，但每次获取都加锁，效率低，**不推荐**。

```java
public class Singleton_04 {
    private static Singleton_04 instance;

    private Singleton_04() {}

    public static synchronized Singleton_04 getInstance() {
        if (instance == null) {
            instance = new Singleton_04();
        }
        return instance;
    }
}
```

### 懒汉式（同步代码块）

if 在锁外，多线程仍可能创建多个实例，**不可用**。

```java
public class Singleton_05 {
    private static Singleton_05 instance;

    private Singleton_05() {}

    public static Singleton_05 getInstance() {
        if (instance == null) {
            synchronized (Singleton_05.class) {
                instance = new Singleton_05();
            }
        }
        return instance;
    }
}
```

### 双重检查锁（DCL）

**推荐**。懒加载 + 线程安全，只有第一次创建时同步。

```java
public class Singleton_06 {
    private static volatile Singleton_06 instance; // volatile 防指令重排

    private Singleton_06() {}

    public static Singleton_06 getInstance() {
        if (instance == null) {                    // 第一次检查
            synchronized (Singleton_06.class) {
                if (instance == null) {            // 第二次检查
                    instance = new Singleton_06();
                }
            }
        }
        return instance;
    }
}
```

> `volatile` 防止指令重排导致拿到未初始化完成的对象。

### 静态内部类

**推荐**。利用类加载机制保证线程安全，且懒加载。

```java
public class Singleton_07 {
    private Singleton_07() {}

    // 内部类懒加载，JVM 保证线程安全
    private static class Holder {
        static final Singleton_07 INSTANCE = new Singleton_07();
    }

    public static Singleton_07 getInstance() {
        return Holder.INSTANCE;
    }
}
```

### 枚举

**推荐**。天然防反射、防多实例，写法最简。

```java
public enum Singleton_08 {
    INSTANCE; // 枚举常量即唯一实例

    public void doSomething() {}
}
```

## 客户端调用

```java
public class Client {
    public static void main(String[] args) {
        Singleton_07 instance1 = Singleton_07.getInstance();
        Singleton_07 instance2 = Singleton_07.getInstance();
        System.out.println(instance1 == instance2); // true

        Singleton_08.INSTANCE.doSomething();
    }
}
```

# 4、源码中的运用

| 案例 | 说明 |
| :--- | :--- |
| `Runtime.getRuntime()` | JDK 经典单例，全局唯一运行时 |
| `Spring Bean` 默认 scope | 容器内每个 Bean 默认单例（与 GoF 单例思想一致，由容器保证） |
| `MyBatis SqlSessionFactory` | 重量级对象，通常全局一份 |
| 枚举单例 | `Effective Java` 推荐写法 |
