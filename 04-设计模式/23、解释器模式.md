# 1、场景引入

简单计算器要支持表达式：`1 + 2`、`3 * 4`。需要把字符串解析成语法结构并求值。若用大量 if-else 解析，难以扩展新运算符。

# 2、普通写法

```java
public int eval(String expr) {
    if (expr.contains("+")) {
        String[] parts = expr.split("\\+");
        return Integer.parseInt(parts[0]) + Integer.parseInt(parts[1]);
    }
    // 每加一种运算符改一处
}
```

**问题**：语法与求值逻辑耦合；扩展运算符/优先级困难。

# 3、设计模式做法

## 介绍

解释器模式（Interpreter）：给定一种语言，定义它的**文法表示**，并定义一个解释器，使用该表示来解释语言中的句子。

**典型结构**

| 角色 | 说明 |
| :--- | :--- |
| AbstractExpression | 抽象表达式，声明 interpret |
| TerminalExpression | 终结符（数字、变量） |
| NonterminalExpression | 非终结符（+、- 等组合） |
| Context | 全局/上下文信息 |

```java
// 抽象表达式
public interface Expression {
    int interpret();
}

// 终结符：数字
public class NumberExpression implements Expression {
    private final int value;
    public NumberExpression(int value) { this.value = value; }
    public int interpret() { return value; }
}

// 非终结符：加法
public class AddExpression implements Expression {
    private final Expression left;
    private final Expression right;

    public AddExpression(Expression left, Expression right) {
        this.left = left;
        this.right = right;
    }

    public int interpret() {
        return left.interpret() + right.interpret(); // 递归求值
    }
}
```

## 客户端调用

```java
public class Client {
    public static void main(String[] args) {
        // 构建语法树：1 + 2
        Expression expr = new AddExpression(
            new NumberExpression(1),
            new NumberExpression(2));
        System.out.println(expr.interpret()); // 3
    }
}
```

实际复杂语法常配合**语法树 + 递归下降/ANTLR** 等工具。

## 注意事项

1. 适合**简单、重复出现的文法**；复杂语法用专用解析器更合适。
2. 类数量随文法规则增多而增加。
3. GoF 23 中使用频率最低之一，但正则、SQL、SpEL 底层有解释思想。
