# 隐式类型转换

自动将一种数据类型转换为另一种数据类型

```python
num_int = 123
num_flo = 1.23

num_new = num_int + num_flo

print("datatype of num_int:", type(num_int)) # int
print("datatype of num_flo:", type(num_flo)) # float

print("Value of num_new:", num_new) # 124.23
print("datatype of num_new:", type(num_new)) # float
```

# 显式类型转换

用函数将对象的数据类型转换为所需的数据类型

```python
# ---------- int ----------
# int(x [, base])：将 x 转换为整数
print(int("123"))          # 123
print(int("101", 2))       # 5（二进制）
print(int(3.7))            # 3（向下取整）

# 易错点：
# print(int("12.3"))       # ValueError


# ---------- float ----------
# float(x)：将 x 转换为浮点数
print(float("3.14"))       # 3.14
print(float(5))            # 5.0


# ---------- str ----------
# str(x)：将对象转换为字符串（面向用户）
print(str(100))            # '100'
print(str([1, 2, 3]))      # '[1, 2, 3]'


# ---------- repr ----------
# repr(x)：将对象转换为“解释器可识别的表达式字符串”
print(repr(100))           # '100'
print(repr("abc"))         # "'abc'"

# 区别示例
print(str("abc"))          # abc
print(repr("abc"))         # 'abc'


# ---------- eval ----------
# eval(str)：执行字符串中的 Python 表达式
print(eval("1 + 2"))       # 3
print(eval("3 * 4"))       # 12

# ⚠️ 危险：不要对不可信字符串使用 eval
# eval("__import__('os').system('rm -rf /')")


# ---------- tuple ----------
# tuple(s)：将序列转换为元组
print(tuple([1, 2, 3]))    # (1, 2, 3)


# ---------- list ----------
# list(s)：将序列转换为列表
print(list((1, 2, 3)))     # [1, 2, 3]


# ---------- set ----------
# set(s)：转换为可变集合（去重）
print(set([1, 1, 2, 3]))   # {1, 2, 3}


# ---------- dict ----------
# dict(d)：创建字典，d 为 (key, value) 元组序列
print(dict([("a", 1), ("b", 2)]))  # {'a': 1, 'b': 2}


# ---------- frozenset ----------
# frozenset(s)：不可变集合
fs = frozenset([1, 2, 3])
print(fs)


# ---------- chr ----------
# chr(x)：整数 → 字符（Unicode）
print(chr(65))             # 'A'


# ---------- ord ----------
# ord(x)：字符 → 整数（Unicode）
print(ord("A"))            # 65


# ---------- hex ----------
# hex(x)：整数 → 十六进制字符串
print(hex(255))            # '0xff'


# ---------- oct ----------
# oct(x)：整数 → 八进制字符串
print(oct(8))              # '0o10'
```
