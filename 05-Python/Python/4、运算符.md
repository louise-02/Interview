# 1、算术运算符

```python
# =========================
# 1. 算术运算符
# =========================
# +   加法：两个对象相加
# -   减法：取负或相减
# *   乘法：数字相乘 / 字符串重复
# /   除法：返回浮点数
# %   取模：返回余数
# **  幂运算：x 的 y 次方
# //  取整除：向下取整

print(5 + 3)      # 8
print(5 - 3)      # 2
print(5 * 3)      # 15
print(5 / 2)      # 2.5
print(5 % 2)      # 1
print(2 ** 3)     # 8
print(5 // 2)     # 2
```

# 2、比较运算符

```python
# =========================
# 2. 比较运算符
# =========================
# ==   等于
# !=   不等于
# >    大于
# <    小于
# >=   大于等于
# <=   小于等于
# ⚠️ 返回 True / False

print(3 == 3)     # True
print(3 != 2)     # True
print(5 > 3)      # True
print(5 <= 3)     # False
```

# 3、赋值运算符

```python
# =========================
# 3. 赋值运算符
# =========================
# =    普通赋值
# +=   加法赋值
# -=   减法赋值
# *=   乘法赋值
# /=   除法赋值
# %=   取模赋值
# **=  幂赋值
# //=  取整除赋值

a = 10
a += 5     # a = a + 5
print(a)   # 15


# ---------- 海象运算符（:=） ----------
# 在表达式中赋值（Python 3.8+）

s = "322313123121"
if (n := len(s)) > 10:
    print(f"String is too long ({n})")
```

# 4、位运算符

```python
# =========================
# 4. 位运算符
# =========================
# &   按位与
# |   按位或
# ^   按位异或
# ~   按位取反
# <<  左移
# >>  右移

print(5 & 3)   # 1
print(5 | 3)   # 7
print(5 ^ 3)   # 6
print(~5)      # -6
print(5 << 1)  # 10
print(5 >> 1)  # 2
```

# 5、逻辑运算符

```python
# =========================
# 5. 逻辑运算符
# =========================
# and   与：前假则前，前真则后
# or    或：前真则前，前假则后
# not   非：取反

print(True and False)   # False
print(True or False)    # True
print(not True)         # False
print(not 2)            # False（非 0 都是真）
```

# 6、成员运算符

```python
# =========================
# 6. 成员运算符
# =========================
# in       是否存在于序列中
# not in   是否不存在于序列中
# 可用于：字符串、列表、元组、集合、字典（key）

print('a' in 'abc')          # True
print(3 in [1, 2, 3])        # True
print('x' not in 'abc')      # True
```

# 7、身份运算符

| **运算符** | **比较的是什么**     | **用途**        |
| ---------- | -------------------- | --------------- |
| ==         | **值是否相等**       | 日常比较        |
| is         | **是否是同一个对象** | 身份判断        |
| id()       | 内存地址             | 调试 / 理解底层 |

```python
# =========================
# 7. 身份运算符
# =========================
# is       是否指向同一个对象（内存地址）
# is not   是否不是同一个对象

a = 222
b = 222
print(a is b)                # True（小整数缓存）
print(id(a) == id(b))        # True
```

# 9、三元运算符（条件表达式）

```python
# =========================
# 9. 三元运算符（条件表达式）
# =========================
# 语法：
# value_if_true if condition else value_if_false

a = 1
b = 2
c = a if a > b else b
print(c)   # 2
```
