# Docker 环境准备

各服务 Docker 部署的公共前置步骤，**只需配置一次**。安装与镜像加速的详细说明也可参考 [Docker 基础](../../../02-技术栈/Docker/Docker.md)。

## 1、安装 Docker

```bash
# 安装依赖
sudo yum install -y yum-utils device-mapper-persistent-data lvm2

# 添加仓库（任选其一）
sudo yum-config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo
# sudo yum-config-manager --add-repo http://mirrors.aliyun.com/docker-ce/linux/centos/docker-ce.repo

# 安装并启动
sudo yum install -y docker-ce docker-ce-cli containerd.io
sudo systemctl start docker
sudo systemctl enable docker
docker -v
```

## 2、配置镜像加速

```bash
sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json > /dev/null <<'EOF'
{
  "registry-mirrors": [
    "https://docker.1ms.run",
    "https://mirror.ccs.tencentyun.com",
    "https://docker.mirrors.ustc.edu.cn"
  ]
}
EOF

sudo systemctl daemon-reload
sudo systemctl restart docker
docker info | grep -A 5 "Registry Mirrors"
```

## 3、镜像拉取与离线传输

### 3.1、拉取镜像

```bash
# 不指定架构（默认拉取本机架构对应的镜像）
docker pull mysql:8.0
docker pull redis:7.2
docker pull portainer/portainer-ce:2.21.4
# 无 tag 时默认拉取 latest
docker pull nginx
```

本机是 x86 Linux 服务器时，不指定架构即可，拉下来的就是 `linux/amd64`。

```bash
# 指定架构（本机架构与目标服务器不一致时必须指定）
docker pull --platform linux/amd64 mysql:8.0
docker pull --platform linux/amd64 redis:7.2
docker pull --platform linux/amd64 portainer/portainer-ce:2.21.4

# arm64 架构（Apple Silicon Mac / ARM 服务器）
docker pull --platform linux/arm64 nginx:1.26
```

| 场景 | 用哪种 |
| ---- | ------ |
| x86 Linux 服务器上直接拉 | 不指定，默认 `linux/amd64` |
| Mac（M 芯片）拉镜像给 x86 Linux 用 | 必须 `--platform linux/amd64` |
| ARM 服务器 | 不指定默认 `arm64`，或显式 `--platform linux/arm64` |

```bash
# 查看本机架构
docker info | grep Architecture
uname -m                    # x86_64 → amd64，aarch64 → arm64

# 查看已拉取镜像的架构
docker inspect mysql:8.0 --format '{{.Os}}/{{.Architecture}}'
```

| 架构 | 说明 |
| ---- | ---- |
| `linux/amd64` | 常见 x86_64 服务器（最常见） |
| `linux/arm64` | ARM 服务器、Apple Silicon Mac |
| `linux/arm/v7` | 32 位 ARM 设备 |

### 3.2、离线传输（内网环境）

内网机器无法拉取镜像时，在有网机器拉取并导出，再拷贝到内网导入：

```bash
# 有网机器：拉取并导出

# 方式1：不指定架构（本机与目标服务器同为 x86 Linux）
docker pull mysql:8.0
docker save -o mysql-8.0.tar mysql:8.0

# 方式2：指定架构（Mac 跳板机给 x86 Linux 服务器准备镜像）
docker pull --platform linux/amd64 mysql:8.0
docker save -o mysql-8.0.tar mysql:8.0

docker pull --platform linux/amd64 portainer/portainer-ce:2.21.4
docker save -o portainer-ce.tar portainer/portainer-ce:2.21.4

# 内网机器：导入
docker load -i mysql-8.0.tar
docker load -i portainer-ce.tar

# 验证
docker images
docker inspect mysql:8.0 --format '{{.Os}}/{{.Architecture}}'
```

### 3.3、删除镜像

```bash
docker rmi mysql:8.0              # 按名称:标签删除
docker rmi abc123def456           # 按镜像 ID 删除
docker rmi -f mysql:8.0           # 强制删除

# 删除多个
docker rmi mysql:8.0 redis:7.2 nginx:1.26

# 删除悬空镜像（无标签、未被使用）
docker image prune

# 删除所有未使用的镜像（未被任何容器引用）
docker image prune -a

# 查看镜像占用空间
docker system df
```

> 镜像被容器使用时无法删除，需先 `docker rm` 删除容器，或加 `-f` 强制删除。

## 4、创建挂载目录

所有 Docker 服务的数据统一放在 `/data/docker/` 下，与 yum/二进制安装的 `/data/<服务>/<版本>/` 区分：

```bash
for dir in \
  mysql/{conf,data,logs} \
  redis/{conf,data} \
  nginx/{conf,conf.d,html,logs} \
  clickhouse/{conf,data,logs} \
  zookeeper/{data,logs} \
  kafka/data \
  rabbitmq/{data,logs} \
  fastdfs/{tracker,storage} \
  jenkins/data \
  nacos/{logs,data} \
  portainer/data
do
  sudo mkdir -p /data/docker/$dir
done
sudo chmod -R 755 /data/docker
```

目录明细见 [0、目录规划.md](./0、目录规划.md)。

## 5、常用命令

```bash
# 进入 compose 目录
cd /path/to/Deploy/docker

# 启动 / 停止 / 查看
docker compose -f mysql.yml up -d
docker compose -f mysql.yml down
docker compose -f mysql.yml ps
docker compose -f mysql.yml logs -f
```
