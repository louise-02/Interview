# Docker 偏生产部署说明

> 公共步骤见 [1、环境准备.md](./1、环境准备.md)，目录规范见 [0、目录规划.md](./0、目录规划.md)。

本文档说明 **Docker 偏生产** 与「开发单容器 up」、与 **yum/二进制正式生产** 的边界。各服务的 **参数含义** 仍在对应 MD 的「配置与运维」章节；此处只讲 **compose + 挂载 + 检查清单**。

## 适用场景

| 场景 | 推荐 |
| ---- | ---- |
| 本地 / 联调 / PoC | 默认 `*.yml` + 最小配置即可 |
| 内网、容器化团队、非核心库 | **偏生产 Docker**（本文 + `conf/` 示例） |
| 核心库 HA、强合规、公网 | **yum / 二进制**（见各服务「部署方式推荐」） |

## 部署顺序（每个服务通用）

```
1. mkdir /data/docker/<服务>/
2. 复制 docker/conf/<服务>/ 示例到挂载目录（或改 compose 环境变量）
3. 修改 IP、密码、内存相关项
4. docker compose -f xxx.yml up -d
5. 初始化账号、防火墙、备份（见各服务「配置与运维」）
```

## 配置文件 vs 环境变量

| 方式 | 服务 | 示例位置 |
| ---- | ---- | -------- |
| **挂载配置文件** | MySQL、Redis、Nginx、ClickHouse、RabbitMQ | [conf/](./conf/) |
| **compose 环境变量** | Kafka、Zookeeper、Nacos | [kafka-kraft.prod.example.yml](./kafka-kraft.prod.example.yml) |
| **两者** | Nacos（MySQL 持久化 + env） | [nacos-mysql.yml](./nacos-mysql.yml) |

## 偏生产检查清单

### compose 通用

- [ ] 镜像使用 **固定 tag**，不用 `latest`
- [ ] `restart: unless-stopped`
- [ ] 数据、日志、配置 **volume 挂载**到 `/data/docker/`
- [ ] 修改默认密码；敏感项用 `.env`（勿提交 git）
- [ ] 按需设置 `mem_limit`（与 `conf/` 内内存参数一致）
- [ ] 端口仅对内网开放（防火墙 / 不映射公网）
- [ ] 已有 `healthcheck` 的服务确认通过

### 必须挂 conf 的服务

- [ ] **Redis**：`requirepass`、`maxmemory`、AOF、`rename-command`
- [ ] **MySQL**：`conf/my.cnf` 含 Buffer Pool、慢日志、binlog
- [ ] **Nginx**：`nginx.conf` + `conf.d/`，HTTPS 证书目录
- [ ] **ClickHouse**：`users.d/` 强密码；混部调内存比例
- [ ] **RabbitMQ**：`rabbitmq.conf` 内存水位、磁盘下限

### 主要靠 env 的服务

- [ ] **Kafka KRaft**：`ADVERTISED_LISTENERS` 为本机 IP；副本 / 禁自动建 topic（多机各一份 compose）
- [ ] **Zookeeper**：`ALLOW_ANONYMOUS_LOGIN=no`（生产）；三节点三台宿主机
- [ ] **Nacos**：使用 `nacos-mysql.yml`，不用 Derby 单机

### 高可用说明

单份 compose **不等于** 集群 HA。Kafka / ZK **三节点** = 三台机器各部署一份 compose，分别改 `NODE_ID`、`ADVERTISED_LISTENERS`、`QUORUM_VOTERS`。

## 示例配置目录

```
docker/conf/
├── mysql/my.cnf
├── redis/redis.conf
├── nginx/nginx.conf
├── nginx/conf.d/default.conf
├── clickhouse/users.d/default-password.xml
└── rabbitmq/rabbitmq.conf
```

复制示例（在 Deploy/docker 目录下执行）：

```bash
# Redis 示例
mkdir -p /data/docker/redis/conf /data/docker/redis/data
cp conf/redis/redis.conf /data/docker/redis/conf/

# MySQL 示例
mkdir -p /data/docker/mysql/{conf,data,logs}
cp conf/mysql/my.cnf /data/docker/mysql/conf/

# Nginx 示例
mkdir -p /data/docker/nginx/{conf,conf.d,html,logs}
cp conf/nginx/nginx.conf /data/docker/nginx/conf/
cp conf/nginx/conf.d/default.conf /data/docker/nginx/conf.d/
```

## 与「配置与运维」的关系

| 内容 | 写在哪 |
| ---- | ------ |
| 内存比例、副本数、持久化策略 | 各服务 MD → **配置与运维** |
| 可挂载的文件内容 | **docker/conf/** |
| Docker 特有路径、compose 改项 | 各服务 MD → **docker 安装 → 偏生产配置** |
