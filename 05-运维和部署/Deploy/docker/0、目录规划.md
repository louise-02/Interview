# Docker 部署目录规划

Docker 部署统一使用 `/data/docker/<服务名>/` 作为宿主机挂载根目录。

与 yum/二进制安装路径 `/data/<服务名>/<版本>/` 区分开，避免混用。

> 环境准备（安装 Docker、镜像加速、一键建目录）见 [1、环境准备.md](./1、环境准备.md)

## 统一目录结构

```
/data/docker/
├── mysql/
│   ├── conf/          → /etc/mysql/conf.d
│   ├── data/          → /var/lib/mysql
│   └── logs/          → /var/log/mysql
├── redis/
│   ├── conf/          → redis.conf
│   └── data/          → /data
├── nginx/
│   ├── conf/          → nginx.conf
│   ├── conf.d/        → /etc/nginx/conf.d
│   ├── html/          → /usr/share/nginx/html
│   └── logs/          → /var/log/nginx
├── clickhouse/
│   ├── conf/          → /etc/clickhouse-server
│   ├── data/          → /var/lib/clickhouse
│   └── logs/          → /var/log/clickhouse-server
├── zookeeper/
│   ├── data/          → /bitnami/zookeeper/data
│   └── logs/          → /bitnami/zookeeper/logs
├── kafka/
│   └── data/          → /bitnami/kafka/data
├── rabbitmq/
│   ├── data/          → /var/lib/rabbitmq
│   └── logs/          → /var/log/rabbitmq
├── fastdfs/
│   ├── tracker/       → /var/fdfs
│   └── storage/       → /var/fdfs
├── jenkins/
│   └── data/          → /var/jenkins_home
├── nacos/
│   ├── logs/          → /home/nacos/logs
│   └── data/          → /home/nacos/data（Derby 模式）
└── portainer/
    └── data/          → /data（Portainer 配置与数据）
```

## 待补充（常用中间件）

以下中间件 Docker 部署也很常见，可按需补充文档：

| 服务 | 用途 | 典型镜像 | 优先级 |
| ---- | ---- | -------- | ------ |
| MinIO | 对象存储（S3 兼容） | `minio/minio` | ⭐⭐⭐ 可替代部分 FastDFS 场景 |
| Elasticsearch | 全文检索 / 日志存储 | `elasticsearch:8.x` | ⭐⭐⭐ 配合 Kibana 使用 |
| Prometheus + Grafana | 监控告警 | `prom/prometheus`、`grafana/grafana` | ⭐⭐⭐ 运维监控 |
| Harbor | Docker 私有镜像仓库 | `goharbor/harbor` | ⭐⭐ 内网镜像管理 |
| PostgreSQL | 关系型数据库 | `postgres:16` | ⭐⭐ 部分项目替代 MySQL |
| MongoDB | 文档型数据库 | `mongo:7` | ⭐⭐ NoSQL 场景 |
| GitLab | 代码托管 + CI/CD | `gitlab/gitlab-ce` | ⭐⭐ 可替代 Jenkins + 自建 Git |
