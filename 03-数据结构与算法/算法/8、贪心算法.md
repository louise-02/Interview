# 1、介绍

贪婪算法(贪心算法)是指在对问题进行求解时，在每一步选择中都采取最好或者最优(即最有利)的选择，从而希望能够导致结果是最好或者最优的算法。

贪婪算法所得到的结果**不一定是最优的结果**(有时候会是最优解)，但是都是相对近似(接近)最优解的结果。

# 2、应用场景

**集合覆盖问题**

假设存在下面需要付费的广播台，以及广播台信号可以覆盖的地区。 如何选择最少的广播台，让所有的地区都可以接收到信号

| 广播台 |        覆盖地区        |
| :----: | :--------------------: |
|   K1   | "北京", "上海", "天津" |
|   K2   | "广州", "北京", "深圳" |
|   K3   | "成都", "上海", "杭州" |
|   K4   |     "上海", "天津"     |
|   K5   |     "杭州", "大连"     |

# 3、思路

1、先获取到所有的覆盖地区

2、依次比较几个集合与总集合公共元素的数量，取数量最多的

3、把总集合元素中上次集合的信息删掉，再重复进行上述操作

# 4、代码实现

```java
public class Greed {
    String[] k1 = {"北京", "上海", "天津"};
    String[] k2 = {"广州", "北京", "深圳"};
    String[] k3 = {"成都", "上海", "杭州"};
    String[] k4 = {"上海", "天津"};
    String[] k5 = {"杭州", "大连"};


    @Test
    public void test() {
        doGreed();
    }

    private void doGreed() {
        List<String> list1 = Arrays.stream(k1).collect(Collectors.toList());
        List<String> list2 = Arrays.stream(k2).collect(Collectors.toList());
        List<String> list3 = Arrays.stream(k3).collect(Collectors.toList());
        List<String> list4 = Arrays.stream(k4).collect(Collectors.toList());
        List<String> list5 = Arrays.stream(k5).collect(Collectors.toList());

        HashMap<String, List<String>> map = new HashMap<>();
        map.put("k1", list1);
        map.put("k2", list2);
        map.put("k3", list3);
        map.put("k4", list4);
        map.put("k5", list5);

        List<String> list = new ArrayList<>();
        list.addAll(list1);
        list.addAll(list2);
        list.addAll(list3);
        list.addAll(list4);
        list.addAll(list5);

        list = list.stream().distinct().collect(Collectors.toList());
        List<String> temp = new ArrayList<>();
        String maxKey = null;
        int maxNum = 0;
        List<String> resultList = new ArrayList<>();
        while (list.size() > 0) {
            for (Map.Entry<String, List<String>> entry : map.entrySet()) {
                String key = entry.getKey();
                List<String> value = entry.getValue();
                temp.addAll(list);
                temp.retainAll(value);
                if (key.length() > 0 && temp.size() > maxNum) {
                    maxNum = temp.size();
                    maxKey = key;
                }
                temp.clear();
            }

            list.removeAll(map.get(maxKey));
            resultList.add(maxKey);
            maxKey = null;
            maxNum = 0;
        }

        System.out.println(resultList);
    }
}
```
