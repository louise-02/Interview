# 1、注意事项

mid = left+(right-left)/2 原因是如果数组很大的情况 left+right 可能会溢出int

# 2、递归方式

```java
public class BinarySearch {
    public static void main(String[] args) {
        int[] arr = {1, 10, 12, 15, 16, 20, 30, 40, 50, 65, 70, 80};
        System.out.println(binarySearch(arr, 20));
        System.out.println(binarySearch(arr, 0, arr.length - 1, 20));
    }

    private static int binarySearch(int[] arr, int left, int right, int num) {
        if (left > right) {
            return -1;
        }
        int mid = left+(right-left) / 2;
        if (arr[mid] == num) {
            return mid;
        }
        if (arr[mid] < num) {
            return binarySearch(arr, left + 1, right, num);
        }else {
            return binarySearch(arr, left, right - 1, num);
        }
    }
}
```

# 3、非递归方式

```java
private static int binarySearch(int[] arr, int num) {
    int left = 0;
    int right = arr.length - 1;
    int temp;
    while (left <= right) {
        temp = left+(right-left) / 2;
        int tempNum = arr[temp];
        if (tempNum == num) {
            return temp;
        } else if (num > tempNum) {
            left = temp + 1;
        } else {
            right = temp - 1;
        }
    }
    return -1;
}
```
