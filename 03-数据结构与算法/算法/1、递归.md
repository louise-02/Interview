# 1、相关概念

递归就是方法自己调用自己,每次调用时传入不同的变量，递归有助于编程者解决复杂的问题,同时可以让代码变得简洁。

# 2、应用场景

1、数学问题：8皇后，汉诺塔，阶乘问题，迷宫问题，球和篮子的问题。

2、算法：快排，归并排序，二分查找，分治算法等。

3、将用栈解决的问题。

# 3、需要注意的重要规则

1、执行一个方法时，就创建一个新的受保护的独立空间(栈空间)

2、方法的局部变量是独立的，不会相互影响

3、递归必须向退出递归的条件逼近，否则就是无限递归，死归了

4、当一个方法执行完毕，或者遇到return，就会返回。遵守谁调用，就将结果返回给谁，同时当方法执行完毕或者返回时，该方法也就执行完毕

# 4、阶乘

```java
public Integer recursion(Integer num){
    if (num <= 1){
        return 1;
    }
    return num * recursion(num -1 );
}
```

# 5、迷宫回溯

```java
public class MapRecursion {

    @Test
    public void map() {
        int[][] map = new int[8][7];

        for (int i = 0; i < 8; i++) {
            for (int j = 0; j < 7; j++) {
                map[i][j] = 0;
            }
        }


        for (int i = 0; i < 7; i++) {
            map[0][i] = 1;
            map[7][i] = 1;
        }

        for (int i = 0; i < 8; i++) {
            map[i][0] = 1;
            map[i][6] = 1;
        }


        map[3][1] = 1;
        map[3][2] = 1;

        int initX = 1;
        int initY = 1;
        int endX = 6;
        int endY = 5;
        boolean can = doRecursion(map, initX, initY, endX, endY);
        System.out.println(can);

        for (int i = 0; i < 8; i++) {
            for (int j = 0; j < 7; j++) {
                System.out.print(map[i][j]);
            }
            System.out.println();
        }
    }

    /**
     * 做递归
     * <p>
     * 0 还未通行 1 障碍 2 已经通行且可以走通 3 已经通行但是无法走通
     * 行走规则 下右上左
     *
     * @param map   地图
     * @param initX 初始坐标X
     * @param initY 初始坐标Y
     * @param endX  结束坐标X
     * @param endY  结束坐标Y
     * @return boolean 是否可以通行
     */
    private boolean doRecursion(int[][] map, int initX, int initY, int endX, int endY) {
        if (map[endX][endY] == 2) {
            System.out.printf("X坐标为:%s,Y坐标为:%s%n",initX,initY);
            return true;
        }
        if (map[initX][initY] == 2 ||map[initX][initY] == 3 || map[initX][initY] == 1){
            map[initX][initY] = 3;
            return false;
        }
        map[initX][initY] = 2;
        if (doRecursion(map, initX + 1, initY, endX, endY)) {
            return true;
        }
        if (doRecursion(map, initX, initY + 1, endX, endY)) {
            return true;
        }
        if (doRecursion(map, initX - 1, initY, endX, endY)) {
            return true;
        }
        return doRecursion(map, initX, initY - 1, endX, endY);
    }
}
```

# 6、八皇后

```java
/**
 * 八皇后问题
 * 简介: 一个8*8的方格 要求摆放8个皇后 要求每一个都不在一行一列 或者一条斜线上
 * 求有多少种解法
 *
 * @author louise
 * @date 2022/02/16
 */
public class EightQueen {
    static int time = 0;

    /**
     * main方法 用一个以为数组来解决问题
     * 从数组第一位开始摆放 依次类推 没有摆放成功进行回溯
     *
     * @param args 参数
     */
    public static void main(String[] args) {
        int[] eightQueen = new int[8];
        recursion(eightQueen, 0);
        System.out.println(time);
    }

    private static void recursion(int[] eightQueen, int position) {
        if (position == eightQueen.length) {
            printEightQueen(eightQueen);
            return;
        }

        for (int i = 0; i < eightQueen.length; i++) {
            eightQueen[position] = i;
            if (canPut(eightQueen, position)) {
                recursion(eightQueen, position + 1);
            }
        }
    }

    private static void printEightQueen(int[] eightQueen) {
        System.out.println(Arrays.toString(eightQueen));
        time += 1;
    }

    private static boolean canPut(int[] eightQueen, int i) {
        for (int j = 0; j < i; j++) {
            if (eightQueen[i] == eightQueen[j] || i - j == Math.abs(eightQueen[i] - eightQueen[j])) {
                return false;
            }
        }
        return true;
    }
}
```
