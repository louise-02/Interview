# 标识符

1、在 Python 里，标识符由字母、数字、下划线组成。

2、在 Python 中，所有标识符可以包括英文、数字以及下划线(_)，但不能以数字开头。

3、Python 中的标识符是区分大小写的。

4、**以下划线开头的标识符是有特殊意义的**。以单下划线开头 `_foo` 的代表**不能直接访问的类属性**，需通过类提供的接口进行访问，不能用 from xxx import * 而导入。

5、以双下划线开头的 `__foo` 代表类的私有成员，以双下划线开头和结尾的 `__foo__` 代表 Python 里特殊方法专用的标识，如 `__init__()` 代表类的构造函数。

impot 和 from...import

```python
# =========================
# Python 模块与 import
# =========================


# ---------- 1. 导入整个模块 ----------
# import 模块名
import math

print(math.sqrt(9))     # 3.0
print(math.pi)          # 3.1415926...


# ---------- 2. 从模块中导入指定函数 ----------
# from 模块名 import 函数名
from math import sqrt

print(sqrt(16))         # 4.0


# ---------- 3. 从模块中导入多个函数 ----------
# from 模块名 import func1, func2
from math import sin, cos

print(sin(0))
print(cos(0))


# ---------- 4. 导入模块中所有内容（不推荐） ----------
# from 模块名 import *
# ⚠️ 不推荐：容易污染命名空间
from math import *

print(sqrt(25))         # 5.0
print(pi)               # 3.1415926...


# ---------- 5. 使用别名 ----------
# import 模块名 as 别名
import math as m

print(m.sqrt(36))       # 6.0
print(m.pi)


# ---------- 6. 函数别名 ----------
# from 模块名 import 函数 as 别名
from math import sqrt as square_root

print(square_root(49))  # 7.0
```





# 数据类型

## 0、简述

- 变量存储在内存中的值，这就意味着在创建变量时会在内存中开辟一个空间。

- 基于变量的数据类型，解释器会分配指定内存，并决定什么数据可以被存储在内存中。

- 变量可以指定不同的数据类型，这些变量可以存储整数，小数或字符。

- Python 中的变量赋值不需要类型声明。

- 每个变量在内存中创建，都包括变量的标识，名称和数据这些信息。

- 每个变量在使用前都必须赋值，变量赋值以后该变量才会被创建。

- 变量名必须是大小写英文、数字和_的组合，且不能用数字开头。

- 空值为 None。

```python
# 多变量赋值
a, b, c = 1, 2, "john"
a = b = c = 1
print(a, b, c)

# 变量命名

t_007 = 'T007'
Answer = True

# 解释器作用
a = 'ABC'
# 在内存中创建了一个'ABC'的字符串
# 在内存中创建了一个名为a的变量，并把它指向'ABC'
```

- Python有六个标准的数据类型：

不可变数据：Numbers（数字）、String（字符串）、Tuple（元组）

可变数据：List（列表）、Set(集合)、Dictionary（字典）

## 1、数字类型Number

- 是不可改变的数据类型，这意味着改变数字数据类型会分配一个新的对象。
- Python支持四种不同的数字类型：int（有符号整型）、float（浮点型）、complex（复数）、bool(布尔)。

- Python 还支持复数，复数由实数部分和虚数部分构成，可以用 a + bj，或者 complex(a,b) 表示， 复数的实部 a 和虚部 b 都是浮点型。

```python
import math


# ---------- abs ----------

print(abs(-10))        # 10

# math.log(x [, base])：对数函数
print(math.log(math.e))        # 1.0（默认以 e 为底）

# ---------- log10 ----------

print(math.log10(100))          # 2.0

print(min(1, 5, 3))             # 1

# ---------- round ----------
```

### 随机数函数 random

```python
# =========================
# Python 随机数函数 random
# =========================

import random

# ---------- random ----------
# random.random()：生成 [0.0, 1.0) 之间的随机浮点数
print(random.random())

# ---------- uniform ----------
# random.uniform(x, y)：生成 [x, y] 之间的随机浮点数
print(random.uniform(1, 10))

# ---------- randrange ----------
# random.randrange(start, stop[, step])：从范围内随机取一个整数
print(random.randrange(1, 10))  # 1 ~ 9
print(random.randrange(1, 10, 2))  # 1,3,5,7,9

# ---------- choice ----------
# random.choice(seq)：从序列中随机选一个元素
colors = ["red", "green", "blue"]
print(random.choice(colors))

# ---------- shuffle ----------
# random.shuffle(list)：原地打乱列表顺序（无返回值）
nums = [1, 2, 3, 4, 5]
random.shuffle(nums)
print(nums)

# ---------- seed ----------
# random.seed(x)：设置随机种子（保证结果可复现）
random.seed(10)
print(random.random())
print(random.random())
```

### 三角函数

```python
# =========================
# Python 三角函数 math
# =========================

import math


# ⚠️ Python 的三角函数默认使用「弧度」
# 角度 <-> 弧度转换：
# radians() 角度 → 弧度
# degrees() 弧度 → 角度


# ---------- sin / cos / tan ----------
angle = math.radians(30)   # 30° → 弧度
print(math.sin(angle))     # 0.5
print(math.cos(angle))     # ≈ 0.866
print(math.tan(angle))     # ≈ 0.577


# ---------- asin / acos / atan ----------
print(math.degrees(math.asin(0.5)))   # 30.0
print(math.degrees(math.acos(0.5)))   # 60.0
print(math.degrees(math.atan(1)))     # 45.0


# ---------- atan2 ----------
# math.atan2(y, x)：根据坐标计算角度（常用于方向、向量）
x, y = 1, 1
print(math.degrees(math.atan2(y, x))) # 45.0


# ---------- hypot ----------
# math.hypot(x, y)：sqrt(x*x + y*y)
print(math.hypot(3, 4))                # 5.0


# ---------- radians / degrees ----------
print(math.radians(180))               # π
print(math.degrees(math.pi / 2))       # 90.0
```

## 2、字符串String

- '' "" 都被看作为字符串。
- 加号（+）是字符串连接运算符，星号（*）是重复操作

### 基础操作

```python
# =========================
# Python 字符串基础
# =========================


# ---------- 字符串索引 ----------
word = "Python"

Usage: thingy [OPTIONS]
```

### 内建函数

```python
# =========================
# 字符串内建函数
# =========================

s = "hello python world"


# ---------- 大小写 ----------
# capitalize()：首字母大写，其余字符不变
print(s.capitalize())   # Hello python world

# upper()：全部转为大写
print(s.upper())        # HELLO PYTHON WORLD

# lower()：全部转为小写
print(s.lower())        # hello python world

print("abc123".isalnum())   # True

print("abc".isalpha())      # True

print("123".isdigit())      # True

# islower()：是否全为小写字母（至少包含一个字母）

print(s.split())            # ['hello', 'python', 'world']

print("a,b,c".split(","))   # ['a', 'b', 'c']

lst = ["hello", "python", "world"]

# ---------- 替换 ----------
# replace(old, new[, count])：替换子串
print(s.replace("python", "java"))


# ---------- 开头 / 结尾 ----------
# startswith(prefix)：是否以指定字符串开头
print(s.startswith("hello"))   # True

# endswith(suffix)：是否以指定字符串结尾
print(s.endswith("world"))     # True


# ---------- 长度 ----------
# len(s)：字符串长度
print(len(s))                  # 18
```

## 3、元组Tuple

- 元组用 () 标识。内部元素用逗号隔开。但是**元组不能二次赋值**，相当于只读列表。

### 基础操作

```python
# =========================
# 元组（tuple）基础操作
# =========================

t = (1, 2, 3, 2, 4)


# ---------- 基本函数 ----------
# len(tuple)：返回元组元素个数
print(len(t))               # 5

# max(tuple)：返回最大值
print(max(t))               # 4

# min(tuple)：返回最小值
print(min(t))               # 1

# tuple(seq)：将序列转换为元组
print(tuple("abc"))         # ('a', 'b', 'c')


# ---------- 访问元素 ----------
# 通过索引访问（与 list 一致）
print(t[0])                 # 第一个元素
print(t[1:3])               # 切片（索引 1 ~ 2）
print(t[2:])                # 从索引 2 到结尾


# ---------- 元组方法（只有 2 个） ----------
# count(x)：统计元素 x 出现的次数
print(t.count(2))           # 2

# index(x)：返回元素第一次出现的索引（找不到会抛异常）
print(t.index(3))           # 2


# ---------- 拼接 / 重复 ----------
# 元组支持拼接和重复，但不会修改原元组
t2 = (5, 6)

print(t + t2)               # (1, 2, 3, 2, 4, 5, 6)
print(t2 * 2)               # (5, 6, 5, 6)


# ---------- 元组不可变（重点） ----------
# 元组一旦创建，不能修改元素

# t[0] = 100    # ❌ TypeError: 'tuple' object does not support item assignment


# ---------- 单元素元组 ----------
# ⚠️ 只有一个元素时，必须加逗号

a = (1)
b = (1,)

print(type(a))              # <class 'int'>
print(type(b))              # <class 'tuple'>


# ---------- 元组解包 ----------
# 元组可以一次性赋值给多个变量（非常常用）

x, y = (10, 20)
print(x, y)

# 解包 + 交换变量
a, b = 1, 2
a, b = b, a
print(a, b)
```

## 4、列表List

- 列表用[]表示,是有序的。
- 列表可以完成大多数集合类的数据结构实现。它支持字符，数字，字符串甚至可以包含列表。
- 加号 + 是列表连接运算符，星号 * 是重复操作。

### 基础操作

```python
# =========================
# 列表 List 基础
# =========================

# ---------- 定义列表 ----------
squares = [1, 4, 9, 16, 25]
print(squares)


# ---------- 索引 ----------
# 正向索引：从 0 开始
print(squares[0])      # 1

# 负数索引：从末尾开始，-1 表示最后一个
print(squares[-1])     # 25


# ---------- 切片 ----------
# 切片格式：[start : end]（左闭右开）
print(squares[-3:])    # [9, 16, 25]
print(squares[:4])     # [1, 4, 9, 16]
print(squares[1:4])    # [4, 9, 16]


# ---------- 浅拷贝 ----------
# 使用切片复制一个新列表（常用）
copy_list = squares[:]
print(copy_list)       # [1, 4, 9, 16, 25]


# ---------- 列表拼接 ----------
# + 会生成一个新的列表
new_list = squares + [36, 49, 64]
print(new_list)


# ---------- 列表是可变的 ----------
cubes = [1, 8, 27, 65, 125]
cubes[3] = 64          # 修改指定索引的值
print(cubes)


# ---------- 添加元素 ----------
# append(x)：在列表末尾添加一个元素
cubes.append(216)
cubes.append(7 ** 3)
print(cubes)


# ---------- 切片修改 / 删除 ----------
letters = ['a', 'b', 'c', 'd', 'e', 'f', 'g']

# 替换指定区间
letters[2:5] = ['C', 'D', 'E']
print(letters)         # ['a', 'b', 'C', 'D', 'E', 'f', 'g']

# 删除指定区间（赋值为空列表）
letters[2:5] = []
print(letters)         # ['a', 'b', 'f', 'g']


# ---------- 嵌套列表 ----------
a = ['a', 'b', 'c']
n = [1, 2, 3]

# 列表中可以放列表（二维列表）
x = [a, n]
print(x)               # [['a', 'b', 'c'], [1, 2, 3]]

# 访问嵌套列表
print(x[0])            # ['a', 'b', 'c']
print(x[0][1])         # 'b'
```

### 遍历

```python
lst = ['tic', 'tac', 'toe']

# ---------- 普通遍历 ----------

for v in lst:
    print(v)
# tic
# tac
# toe

# ---------- enumerate ----------
# enumerate(iterable)：在遍历序列时，同时拿到 索引(index) 和 值(value)
# 常用于：需要下标的 for 循环（强烈推荐，替代 range(len(...))）

for i, v in enumerate(lst):
    print(i, v)
# 0 tic
# 1 tac
# 2 toe

# 也可以指定起始索引
for i, v in enumerate(lst, start=1):
    print(i, v)
# 1 tic
# 2 tac
# 3 toe


# ---------- zip ----------
# zip(a, b)：把多个序列“打包”成一组一组的数据
# 遍历时，每次取各序列中相同位置的元素
# ⚠️ 注意：zip 以“最短的序列”为准，超出的元素会被忽略

questions = ['name', 'quest', 'favorite color']
answers = ['lancelot', 'the holy grail', 'blue']

for q, a in zip(questions, answers):
    print(f"What is your {q}? It is {a}.")
# What is your name? It is lancelot.
# What is your quest? It is the holy grail.
# What is your favorite color? It is blue.
```

```python
# pop([index])：删除并返回指定位置的元素（默认最后一个）
last = lst.pop()

print(lst)

# remove(obj)：删除第一个匹配的元素（按值删除）
lst.remove(100)
print(lst)


# ---------- 排序 / 反转 ----------
# reverse()：原地反转列表
lst.reverse()
print(lst)

lst.sort()
print(lst)

# sort(reverse=True)：降序排序

print(lst)


# ---------- 清空 / 复制 ----------

print(lst)                  # []

# copy()：浅拷贝列表
a = [1, 2, 3]
b = a.copy()
print(b)
```

## 6、字典Dictionary

- 无序的
- 与列表的区别是，字典当中的元素是通过键来存取的，而不是通过偏移存取
- 字典用{ }标识，字典由索引(key)和它对应的值value组成。
- 键必须不可变，所以可以用数字，字符串或元组充当，而用列表就不行

### 基础操作

```python
# =========================
# 字典 dict —— 基础操作
# =========================

# 创建字典
d = {}
d['one'] = "This is one"
d[2] = "This is two"

tinyDict = {
    'name': 'runoob',
    'code': 6734,
    'dept': 'sales'
}

# 访问元素
print(d['one'])          # This is one
print(d[2])              # This is two
print(tinyDict)          # {'name': 'runoob', 'code': 6734, 'dept': 'sales'}

# 安全访问（键不存在不报错）
print(tinyDict.get('name'))        # runoob
print(tinyDict.get('age'))         # None
print(tinyDict.get('age', 18))     # 18

# 键是否存在
print('name' in tinyDict)          # True
print('age' in tinyDict)           # False
```

### 遍历

```python
# =========================
# 字典 dict —— 遍历
# =========================

knights = {
    'gallahad': 'the pure',
    'robin': 'the brave'
}

# 遍历 key（默认）
for k in knights:
    print(k)

# 遍历 key（显式）
for k in knights.keys():
    print(k)

# 遍历 value
for v in knights.values():
    print(v)

# 同时遍历 key 和 value（最常用）
for k, v in knights.items():
    print(k, v)
```

### 内建函数

```python
# =========================
# 字典 dict —— 内建函数 & 方法
# =========================

d = {'a': 1, 'b': 2, 'c': 3}

# ---------- 基本函数 ----------

# len(dict)：返回字典键的个数
print(len(d))                 # 3

# str(dict)：返回字典的字符串表示
print(str(d))                 # {'a': 1, 'b': 2, 'c': 3}


# ---------- 查询 ----------

# get(key, default=None)：获取键对应的值（安全，不报错）
print(d.get('a'))             # 1
print(d.get('x'))             # None
print(d.get('x', 0))          # 0


# ---------- 视图对象 ----------

# items()：返回 (key, value) 视图对象
print(d.items())              # dict_items([('a', 1), ('b', 2), ('c', 3)])

# keys()：返回 key 视图对象
print(d.keys())               # dict_keys(['a', 'b', 'c'])

# values()：返回 value 视图对象
print(d.values())             # dict_values([1, 2, 3])


# ---------- 修改 ----------

# update(dict2)：用 dict2 更新当前字典
d.update({'d': 4})
print(d)                      # {'a': 1, 'b': 2, 'c': 3, 'd': 4}


# ---------- 删除 ----------

# pop(key[, default])：删除指定键并返回值
val = d.pop('a')
print(val)                    # 1
print(d)                      # {'b': 2, 'c': 3, 'd': 4}

# popitem()：删除并返回最后一对键和值
k, v = d.popitem()
print(k, v)                   # d 4
print(d)                      # {'b': 2, 'c': 3}


# ---------- 拷贝 ----------

# copy()：返回字典的浅拷贝
d_copy = d.copy()
print(d_copy)                 # {'b': 2, 'c': 3}


# ---------- 创建新字典 ----------

# fromkeys(seq, value=None)：创建新字典
new_dict = dict.fromkeys(['name', 'age'], None)
print(new_dict)               # {'name': None, 'age': None}


# ---------- 清空 ----------

# clear()：删除字典内所有元素（⚠️ 一般放最后）
d.clear()
print(d)                      # {}
```

## 7、特点总结

### **数字 Number**

- 类型：int（整数）、float（浮点数）、complex（复数）、bool(布尔)
- 不可变
- 支持算术运算：+ - * / // % **
- 支持比较运算：== != < > <= >=
- 常用内建函数：
  - abs(x)：返回绝对值
  - round(x[, n])：四舍五入
  - pow(x, y)：x ** y
  - divmod(x, y)：返回商和余数组成的元组
  - int(x)：转换为整数
  - float(x)：转换为浮点数
  - complex(x, y)：创建复数

### **字符串 String**

- 有序，可重复
- 不可变
- 支持索引和切片
- 支持拼接、重复
- 支持格式化：%、str.format()、f-string
- 常用方法：
  - 大小写：
    - capitalize()：首字母大写
    - upper()：全部大写
    - lower()：全部小写
  - 查找/替换：
    - find(sub)：查找子串，找不到返回 -1
    - index(sub)：查找子串，找不到报错
    - replace(old, new[, max])：替换
  - 判断：
    - isalpha()：是否全字母
    - isdigit()：是否全数字
    - isalnum()：是否字母或数字
    - islower()：是否全小写
    - isupper()：是否全大写
  - 分割/拼接：
    - split(sep=None, maxsplit=-1)：分割字符串
    - join(seq)：将序列拼接成字符串
  - 去空格：
    - strip()：去除两端空白
    - lstrip()：去左端空白
    - rstrip()：去右端空白

### **列表 List**

- 有序，可重复
- 可变：可修改元素、添加、删除
- 支持索引和切片
- 常用方法：
  - 添加：
    - append(obj)：末尾添加元素
    - extend(seq)：一次性添加多个元素
    - insert(index, obj)：指定位置插入
  - 删除：
    - pop([index])：删除并返回元素
    - remove(obj)：删除第一个匹配项
    - clear()：清空列表
  - 查找/统计：
    - index(obj)：返回元素索引
    - count(obj)：统计元素出现次数
  - 排序/反转：
    - sort(key=None, reverse=False)：原地排序
    - reverse()：原地反转
  - 拷贝：
    - copy()：浅拷贝

### **元组 Tuple**

- 有序，可重复
- 不可变
- 支持索引和切片
- 常用方法：
  - count(obj)：统计元素出现次数
  - index(obj)：返回元素索引
- 用途：
  - 存储固定数据
  - 可作为字典 key（可哈希）

### **集合 Set**

- 无序，不重复
- 可变：可添加/删除元素
- 不支持索引和切片
- 支持集合运算：并集、交集、差集、对称差集
- 常用方法：
  - 添加/删除：
    - add(obj)：添加元素
    - remove(obj)：删除元素，元素不存在报错
    - discard(obj)：删除元素，元素不存在不报错
    - pop()：随机删除一个元素
    - clear()：清空集合
    - update(*others)：添加多个元素
  - 集合运算：
    - union(*others)：并集
    - intersection(*others)：交集
    - difference(*others)：差集
    - symmetric_difference(other)：对称差集
    - intersection_update(*others)：交集更新
    - difference_update(*others)：差集更新
    - symmetric_difference_update(other)：对称差集更新
  - 判断：
    - issubset(other)：子集
    - issuperset(other)：超集
    - isdisjoint(other)：是否没有交集
  - 拷贝：
    - copy()：浅拷贝

### **字典 Dict**

- 键值对存储，键唯一
- 可变：可增加、修改、删除元素
- 无序（Python3.7+ 保持插入顺序）
- key 不可索引，但可通过 key 访问 value
- 常用方法：
  - 查询：
    - get(key, default=None)：获取 key 的值
    - keys()：返回所有键
    - values()：返回所有值
    - items()：返回 (key, value) 对
  - 修改：
    - update(dict2)：更新字典
  - 删除：
    - pop(key[, default])：删除 key 并返回值
    - popitem()：删除最后一对键值
    - clear()：清空字典
  - 拷贝/创建：
    - copy()：浅拷贝
    - fromkeys(seq, value=None)：用序列创建新字典，所有值初始化为 value

# 字符串和编码

```python
# =========================
# 字符串 & 编码
# =========================

# 字符串在 Python 3 中默认使用 Unicode 编码

# ---------- 字符与 Unicode ----------

print(chr(66))        # 'B'

# decode(encoding)：将 bytes 解码为字符串
s2 = b.decode('utf-8')
print(s2)              # '中文'

# ---------- 常用字符串检查 ----------
s = 'Hello123'

# ---------- 常用编码函数 ----------
```
