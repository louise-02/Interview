# 1、捕获异常 try / except

```python
# =========================
# 1. 捕获异常 try / except
# =========================
# try 中放可能出错的代码
# except 捕获指定异常，如果未指定则捕获全部异常
# else：没有异常时执行
# finally：无论是否异常都会执行

try:
    i = 2 + '2'
except TypeError as error:
    print(error)
except (RuntimeError, TypeError, NameError):
    pass
else:
    print('没有异常的时候执行')
finally:
    print('无论如何都会执行')
```

# 2、抛出异常 raise

```python
# =========================
# 2. 抛出异常 raise
# =========================
# raise 主动抛出一个异常
# 常用于参数校验、逻辑校验

x = 10
if x > 5:
    raise Exception('x 不能大于 5。x 的值为: {}'.format(x))
```

# 3、自定义异常

```python
# =========================
# 3. 自定义异常
# =========================
# 自定义异常通常继承 Exception

class MyError(Exception):
    def __init__(self, value):
        self.value = value

    def __str__(self):
        return repr(self.value)

try:
    print(MyError(2 * 2))
    raise MyError(2 * 2)
except MyError as e:
    print('My exception occurred, value:', e)
```

# 4、with 语句（预定义清理行为）

```python
with open("myfile.txt") as f:
    for line in f:
        print(line, end="")
```
