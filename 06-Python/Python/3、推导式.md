Python 推导式（Comprehension）

推导式用于：从一个可迭代对象，快速生成新的数据结构。

优点：代码简洁、可读性高、性能好（比 for + append 更优雅）。

# 列表推导式 List Comprehension

```python
# =========================
# 1. 列表推导式 List Comprehension
# =========================
# 语法：
# [表达式 for 变量 in 可迭代对象]
# [表达式 for 变量 in 可迭代对象 if 条件]

names = ['Bob', 'Tom', 'alice', 'Jerry', 'Wendy', 'Smith']

# 过滤长度大于 3 的名字，并转为大写
new_names = [name.upper() for name in names if len(name) > 3]
print(new_names)
# ['ALICE', 'JERRY', 'WENDY', 'SMITH']

# 等价于：
# result = []
# for name in names:
#     if len(name) > 3:
#         result.append(name.upper())
```

# 字典推导式 Dict Comprehension

```python
# =========================
# 2. 字典推导式 Dict Comprehension
# =========================
# 语法：
# {key_expr: value_expr for item in 可迭代对象}
# {key_expr: value_expr for item in 可迭代对象 if 条件}

listdemo = ['Google', 'Runoob', 'Taobao']

# 以字符串为 key，长度为 value
new_dict = {key: len(key) for key in listdemo}
print(new_dict)
# {'Google': 6, 'Runoob': 6, 'Taobao': 6}

# 带条件的字典推导式
filtered_dict = {k: len(k) for k in listdemo if k.startswith('G')}
print(filtered_dict)
# {'Google': 6}
```

# 集合推导式 Set Comprehension

```python
# =========================
# 3. 集合推导式 Set Comprehension
# =========================
# 语法：
# {表达式 for 变量 in 可迭代对象}
# {表达式 for 变量 in 可迭代对象 if 条件}

# 去除 a、b、c
s = {x for x in 'abracadabra' if x not in 'abc'}
print(s)
# {'d', 'r'}

# 计算平方并去重
set_new = {i ** 2 for i in (1, 2, 3)}
print(set_new)
# {1, 4, 9}
```

# 生成器表达式

```python
# =========================
# 4. 生成器表达式（不是元组推导式）
# =========================
# 语法：
# (表达式 for 变量 in 可迭代对象)
# ⚠️ 返回的是生成器对象，不是元组
# ⚠️ 数据是“按需生成”的（惰性计算），只能遍历一次

gen = (x for x in range(1, 10))
print(gen)
# <generator object ...>

# 使用 tuple() 转换为元组
t = tuple(gen)
print(t)
# (1, 2, 3, 4, 5, 6, 7, 8, 9)


# =========================
# 生成器表达式的主要用途
# =========================

# ---------- 1. 节省内存（大数据场景） ----------
# 不会一次性把所有数据加载到内存
gen = (x * x for x in range(10_000_000))
# 此时几乎不占内存，只有在使用时才计算


# ---------- 2. 流式处理数据 ----------
# 常用于：文件、日志、网络数据等
lines = (line for line in open("app.log") if "ERROR" in line)

for line in lines:
    print(line)


# ---------- 3. 作为函数参数（非常常见） ----------
# 很多内建函数天然支持生成器
nums = (x for x in range(1, 100))

print(sum(nums))     # 求和
# print(max(nums))   # ❌ 此时 nums 已被消费，不能再用


# ---------- 4. 替代中间 list（提高性能） ----------
# ❌ 会创建中间列表
total = sum([x * x for x in range(1, 1000)])

# ✅ 不创建中间列表（推荐）
total = sum(x * x for x in range(1, 1000))


# ---------- 5. 管道式写法（可读性好） ----------
data = range(1, 20)

result = (
    x * 2
    for x in data
    if x % 2 == 0
)

for v in result:
    print(v)


# ---------- 6. 和 for 循环完美配合 ----------
gen = (x for x in range(5))

for x in gen:
    print(x)


# =========================
# 生成器表达式使用场景总结
# =========================
# ✔ 数据量大
# ✔ 只遍历一次
# ✔ 不需要索引、不需要随机访问
# ✔ 作为 sum / max / any / all 等函数参数
# ✔ 文件、日志、流式数据处理

# ❌ 不适合：
# ✘ 需要多次遍历
# ✘ 需要下标访问
# ✘ 需要频繁判断长度
```

# 推导式小总结

```python
# =========================
# 推导式小总结
# =========================
# []  → 列表推导式，直接生成 list
# {}  → 集合推导式 或 字典推导式（有 key:value）
# ()  → 生成器表达式（惰性计算，节省内存）
```
